# r24: 곡선 DAgger 복원 데이터 (2026-09-15 저녁)

앞선 매듭: `20260915_1527`(r23 기각). r23까지의 결론 = **v10 진동은
업웨이트로 못 잡고**, 근본은 **"시연이 너무 완벽해 곡선 복원 데이터 부재"**.

## 문제 재확정 (사용자 라이브 관찰)

r21 데모에서 **직선은 정상, 곡선에서만 밟음**. 대칭 패턴:
- 2차선(바깥) 곡선 → 왼쪽(안쪽=점선 쪽)
- 1차선(안쪽) 곡선 → 오른쪽(바깥=점선 쪽)

→ **곡선에서 양 차선이 공유 점선(mid-track)으로 붕괴**. 모델의 차선
조건화가 곡선에서 약해져, 가장 뚜렷한 시각특징(점선 마킹)으로 끌려감.
선생(pure pursuit lg0.6)은 티어 무관 0.24~0.28 m로 정상 → 모델이 곡선
편향을 증폭한 것.

## 왜 6만장인데도 못 하나 (설계 근거)

YOLO+세그멘테이션(2~3천장)은 **인식만** 배우고 조향은 결정적
컨트롤러(cross-track 피드백)가 함 → 폐루프 복원 보장. SmolVLA는 픽셀→행동을
통째 모방, 피드백 법칙 없음 → **밀린 상태에서 복원을 데이터로 배워야 하는데
그 데이터가 없음**(covariate shift, DART/DAgger). 프레임 수(양)가 아니라
**분포(복원 상태 포함 여부)**가 관건.

## r24 계획 — 곡선 표적 DAgger

`collect_corpus.py`에 이미 있는 DAgger 모드(`--start-poses-file`) 활용:
정책 자신의 오차 상태에서 시작 → 선생이 정확히 그 상태에서 복원.
직선은 이미 정상이라 **곡선에만 표적**(낭비 없음).

| 단계 | 내용 | 상태 |
|---|---|---|
| 1. 오차 수집 | r21을 주행시켜 곡선 구간(idx 78-115·147-197·250-315·356-398)에서 오프셋>0.35m 포즈를 gz 실측 로깅 (`harvest_curve_errors.py`). 양 차선 × normal/fast | 진행 중 |
| 2. 복원 수집 | 오라클(lg0.6)이 그 포즈들에서 복원 시연 (`--start-poses-file`) | 대기 |
| 3. 재학습 r24 | v10 순항 + DAgger 곡선복원, 자연가중, resample-comp, v9 액션 0 | 대기 |

### 전체 아크 결론 (r22~r25) — 논문급 발견

| 구성 | 선생 | 2차선·보통 |
|---|---|---|

**진동원 = 오라클 선생(pure pursuit) 자체.** 오라클 데이터(순항/복원, 단독/
혼합 무관)를 넣으면 폐루프 imitation이 진동. **YOLO 인식 선생(v3y)만
안정.** 오라클은 개루프 추종 0.24m로 깨끗한데 flow-matching 모방 시 한계
사이클. **"복원 데이터" 방향 전체가 막힘** — 유일한 깨끗한 복원 선생이
오라클이라. **논문 프레이밍**: *개루프 선생 지표(추종 정확도)가 폐루프 모방
안정성을 예측하지 못한다; pure-pursuit 오라클(0.24m 추종)은 모방 시 진동,
YOLO 인식 선생은 안정.* r16~r25 감사 트레일 + lane_probe가 정량 증거.

**채택 유지: r21** (v3y 액션, 2차선 normal 0%). 곡선 밟음(1차선/빠름)은
v3y 천장 — 오라클 복원으로 못 고침(더 나빠짐).
