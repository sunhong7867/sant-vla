## 1. 구조 — VLM 이 고르고 VLA 가 간다

| 역할 | 담당 |
|---|---|
| 어느 물체인가 (색·종류·미학습 물체·묘사·좌/우) | Qwen2.5-VL 박스 → bearing = atan((320−u)/f) (`goal_from_scene_node.py`) |
| 얼마나 먼가 | 2D 라이다 (목표 방향 ±5° 최근접) |
| 그 점까지 가서 서기 | SmolVLA g5d (state 6 = [v, ω, δ, goal_bearing, goal_dist, standstill], 문장 상수 `Target.`) |
| 정차 | 브리지 게이트(standoff 안이면 hold) — 코드 |

교수님께 보고할 문장: "새 물체를 알아보는 것은 VLM, VLA 는 '가리킨 점으로 가서 서기' 하나를 배웠다.
C 를 만든 것은 VLM+VLA 계층형이다." VLA 단독 일반화가 아니다.

## 2. 사용자 목록 중 가능성 높은 것 (g5d P2 통과 전제)

| 항목 | 전망 | 근거 |
|---|---|---|
| 차선 무시하고 목표 지점 이동 | 높음 | g5d 학습 동작 그대로 |
| 다른 색 꼬깔 | 높음 | 색 구별은 VLM |
| 꼬깔 말고 다른 물체 | 높음 | VLM 이 아는 물체면 됨 |
| 꼬깔 2~3 개 중 하나 지정 | 높음 | 학습(gv2b)에도 K=2~4 물체. 경로를 막는 배치는 피한다(회피 없음) |
| 차선 따라서 목표 지점 이동 | **제외** | g5d 는 direct 데이터만 학습, 차선 모드 없음 |

추가로 가능성 높은 확인: 표현 바꾸기(한/영), 묘사로 지정("멸종한 생물"→공룡), 위치로 지정("왼쪽 물체"),
물체 옮기면 따라가기(위치 암기 아님 대조), 출발 위치·방향 바꾸기(±25°, 6.5~12.5 m 안).
중간: "두 물체 사이" (아래 P3a 에서 실패), 차선 따라 가기(학습 필요).

주의:
- 성공 = 목표 standoff+1.5 m 안 정차. 정차 자체는 게이트(코드)가 하고, 정책은 조향한다.
- "가장 가까이 선 물체 = 목표" 는 main 13/20, alt 9/20. 목표 standoff(≈3.9 m)에서 서는데 물체가 붙어 있으면
  다른 물체가 더 가까운 경우다(예: 목표 3.94 m, 옆 물체 1.93 m). **회피가 없으므로 목표 가는 길 옆 물체를 스친다** — 시연 배치는 간격을 둔다.
- P4(VLM 연결, 미학습 도형) 는 아직 안 돌렸다.
- 10-13 11:00 재확인: 같은 하네스로 P2 2 장면 × 2 목표 4/4 STOPPED (가까운 물체 기준 2/4).
