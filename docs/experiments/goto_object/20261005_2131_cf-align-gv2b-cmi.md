## 1. cf_align: sidecar 의 프레임 정렬은 정확하다

**질문.** rp3(cf-sidecar 학습, r26 베이스 10k)의 이름 반사실이 22/42(우연 50 %)이고 예측
횡 차이 비율이 0.03 이었다. cf 라벨이 "같은 화면 + 다른 이름 → 다른 행동"을 가르치는
장치인데 효과가 r52(방향 단어, 34/42, 0.09)보다 나쁘다. 라벨이 엉뚱한 프레임에 붙었을
가능성을 먼저 배제해야 한다. `code/course/cf_align.py` 는 직전 세션이 13:37 에 작성해 두고
실행하지 않은 상태였다.

**방법.** sidecar 의 행 인덱스 `k`(packed `resampled_10hz.jsonl` 기준)가 lerobot
`frame_index` 와 같은 프레임을 가리키는지, 두 쪽의 행동 벡터를 직접 비교했다.

**결과 (8 에피소드 × 7 지점: k=0, 10, 20, 중간, 끝−20, 끝−5, 끝).**

```
ep 128: lerobot 169 rows 154 (diff 15)  mismatch 0
ep 129: lerobot 155 rows 140 (diff 15)  mismatch 0
ep 130: lerobot 156 rows 141 (diff 15)  mismatch 0
ep 131: lerobot 146 rows 131 (diff 15)  mismatch 0
ep 132: lerobot 144 rows 129 (diff 15)  mismatch 0
ep 133: lerobot 136 rows 121 (diff 15)  mismatch 0
ep 134: lerobot 136 rows 121 (diff 15)  mismatch 0
ep 135: lerobot 173 rows 158 (diff 15)  mismatch 0
```

- 불일치 **0건**. `lerobot a0` 와 `row a` 가 모든 지점에서 완전히 같다.
- 행 수 차이가 모든 에피소드에서 **정확히 15** 로 같다 → 꼬리 쪽 고정 절단(3 초 행동 구간이
  잡히지 않는 마지막 프레임들). 머리 쪽 밀림이면 k=10 에서 이미 어긋나는데 그렇지 않다.

**결론.** cf 라벨은 의도한 프레임에 붙었다. **rp3 의 음성 결과는 인덱싱 버그가 아니라 실제
결과다.** 합성 반사실 라벨의 다른 하이퍼파라미터 조합을 더 돌리는 것은 권하지 않는다.

## 2. 음성 결과의 유력한 원인: 운동학 교사가 횡 이동을 과소하게 낸다

`cf_align` 출력에는 운동학 교사(`goto_kinematic.rollout`, cf 라벨을 만든 그 교사)와 실제
시연의 3 초 횡 끝점이 같이 찍힌다.

| 에피소드 | 실제 시연 | 운동학 교사 | 차이 |
|---|---|---|---|
| ep 128 | 0.497 m | 0.292 m | −0.205 m |
| ep 132 | 0.482 m | 0.216 m | −0.266 m |
| ep 130 (거의 직진) | 0.033 m | 0.018 m | −0.015 m |

굽은 접근에서 교사가 횡 이동을 약 55 % 적게 낸다. cf 라벨은 전부 이 교사로 생성됐으므로,
**가르치려는 대조량 자체가 과소 표현**된다. 시연의 좌우 폭이 0.545 m 인데 라벨이 그 절반만
벌어지면 "이름이 바뀌면 경로가 이만큼 달라진다"는 신호가 처음부터 약하다.

단, 이것은 n=3 에서 본 관찰이고 과소 횡이동이 음성 결과의 **원인임을 분리 측정하지는
않았다**. 라벨 크기를 보정한 대조 실험은 돌리지 않았다.

## 6. CMI 축 이름 버그: 이 검증은 지금까지 한 번도 실행되지 않았다

`finalize_corpus.sh` 의 `3/4 conditional mutual information` 단계가 세 축 모두 이렇게 끝났다.

```
--- axis=ordinal
no resampled episodes in .../session_20261005_190744 — run resample_episodes.py first
```

그런데 리샘플은 `accepted 68/68` 로 성공했고 `resampled_10hz.jsonl` 은 68 개 전부 있었다.

**원인.** 에피소드 `meta.json` 의 값은 `cf_axis = 'goto_target'` 인데 `finalize` 는
`measure_cmi.py --axis ordinal|lane|speed` 로 호출한다. `verify_corpus.py:487` 은
`{"goto_target": "ordinal", "goto_mode": "lane", "zone": "ordinal", "floor": "none"}` 로 변환해
비교하지만, `measure_cmi.py` 의 `load_session` 은 **변환 없이 원값과 비교**해서 전부 걸러냈다.

이전 실행들은 verify FAIL 로 이 단계에 도달조차 못 했기 때문에 드러나지 않았다. gv2b 가 처음으로
통과해 이 단계에 닿았다.

**조치.**
- `measure_cmi.py` 에 `AXIS_ALIAS` 추가 — `verify_corpus.py` 와 같은 변환표.
- 빈 결과 메시지를 두 경우로 분리. 기존 메시지는 항상 "리샘플을 먼저 돌려라"라고 했고, 그것이
  바로 이 버그를 가린 원인이다. 이제 축에 에피소드가 없으면 그렇게 말한다:
  `no episodes on axis=speed ... (68 resampled episode(s) present on other axes)`.

**첫 측정 결과 (gv2b, axis=ordinal, n=68 ep / 9983 샘플 / 사용 가능 버킷 75개).**

|  | 가중 평균 | 가중 중앙값 |
|---|---|---|
| I(a;instr\|obs) plug-in | 1.160 b | 0.995 b |
| Miller-Madow | 1.193 b | 1.023 b |
| 셔플 대조 | 0.195 b | 0.136 b |
| **디바이어스 (plug-in − 셔플)** | **0.965 b** | **0.909 b** |

- 버킷 분포(디바이어스): p50 0.887 b, p75 1.152 b, p90 1.443 b, peak 1.693 b.
  이 축의 상한은 log2(n_values) = 3.81 b.
- 0.5 b 이상 버킷에 든 프레임 90 %.
- GATE(peak ≥ 0.8 b AND 0.5 b 초과 프레임 ≥ 20 %): **PASS**.
- 추정기 노이즈 하한 0.195 b.

**이 수치가 말하는 것과 말하지 않는 것.** 이것은 **시연 데이터**의 성질이다. 같은 관측
버킷 안에서 지시가 교사의 행동에 대해 평균 0.965 bit 를 갖는다 — 즉 이 코퍼스에서는 화면만으로
행동이 결정되지 않고 문장을 읽어야 한다. **학습된 정책이 문장을 읽는다는 뜻은 아니다.**
정책 쪽 측정은 여전히 이름 반사실 22/42(우연, g1 학습 체크포인트 rp3, n=42 짝)이다.

따라서 현재 그림은 "데이터에 언어 의존성이 없어서 못 배운다"가 **아니다**. 적어도 gv2b
코퍼스에는 0.965 bit 가 있고, 그런데도 정책이 쓰지 않는다. 단, 이 CMI 는 gv2b(신규 v2 설계,
68 ep)에서 잰 것이고 **rp1~rp3 가 학습한 g1 코퍼스에서는 재지 않았다.** 두 코퍼스를 동일시해서는
안 된다.

**재현.**
```bash

  src/sant_vla_pkg/data_course_multiobj/session_20261005_190744 --axis ordinal
```

## 7. 범위 (vla-scope-guard)

- CMI 0.965 b 는 **시연 데이터**의 조건부 상호정보량이다. 모델의 언어 이해·사용에 대한 근거가
  아니다.
- 지시는 열린 자연어가 아니다. goto 축에서 변하는 것은 시야 안 물체 2~4 개 중 하나를 가리키는
  **이름(또는 방향 단어)** 이고, 플릿은 학습 14 종으로 고정돼 있다.
- gv2b 의 verify PASS 는 **데이터 설계 기준**(짝의 경로가 리셋 노이즈의 5 배 이상 갈라짐)을
  통과했다는 뜻이고, 정책 성능과 무관하다.
- 폐루프 성능은 이 문서에서 측정하지 않았다. r52 단계의 수치(T1:pos 목표 최근접 33 %, 우연
  29 %)가 최신이다.
- **문장 없이 학습한 기준선(vision-action only)은 여전히 돌리지 않았다.** 언어 조건화가 성능
  차이의 원인이라는 주장은 이 비교 없이는 할 수 없다.
- cf 라벨의 과소 횡이동(2 절)은 n=3 관찰이며 음성 결과의 원인으로 분리 측정되지 않았다.
