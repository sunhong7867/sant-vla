## 4. 원인: 왼쪽 쏠림 (`server/code/course/probe_frames.py`, 신규)

**방법:** E 의 출발 화면 20 장에 "left" / "right" / null 문장을 각각 넣어, 청크의 3 s 횡 끝점을 비교했습니다. + 가 왼쪽입니다.

| 상태 입력 | null 의 횡 끝점 | left 가 right 보다 왼쪽 | right 문장이 실제로 오른쪽(< 0) |
|---|---|---|---|
| 학습 에피소드 k=3 상태 | +0.74 ~ +1.03 m | 20/20 | **0/20** (w=1, 3, 6 모두) |
| 상태 0 | +0.59 ~ +0.67 m | 20/20 | 0/20 |

- 단어 효과의 방향은 매번 맞습니다(20/20).
- 그러나 모든 문장의 기준 경로가 0.6~0.9 m 왼쪽으로 쏠려 있고, "right" 문장은 이 기준을 넘지 못합니다.
- 증폭은 "left" 를 더 왼쪽으로 밀 뿐입니다. "right" 의 cond − null 이 거의 0 이기 때문입니다.
- 쏠림의 원인으로 추정하는 것은 두 가지입니다. 직접 분리해 보지는 않았습니다.
  - 데이터의 목표 쪽 불균형: 왼쪽 278 / 오른쪽 211 / 정면 336.
  - 반시계 방향 트랙에서 학습한 베이스(r26)와 Stanley 순항 데이터의 좌회전 습관.
