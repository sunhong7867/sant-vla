## 2. 프레임 23 %가 잘못 라벨돼 있었다 — 재수집 없이 고침

코퍼스는 에피소드당 문장 하나다. "왼쪽"으로 시작한 에피소드는 차가 선회해 물체가 정면에 온
뒤에도 라벨이 "왼쪽"이다. 폐루프 VLM 재질의 구조에서 그 프레임의 정답은 "정면"이다.

| | 비율 |
|---|---|
| 라벨 = 현재 섹터 | 77 % |
| **다름** | **23 %** (right→ahead 12.0 %, left→ahead 11.4 %) |

`to_lerobot.py` 가 `ds.add_frame({**frame, "task": task})` 로 task 를 프레임 딕트에 넣으므로
LeRobot 이 프레임별 문장을 받는다. `--sector-per-frame` 을 추가해 **재수집 없이** 재라벨했다.

**검증:** 292 ep 전부 라벨, **섹터 전환 에피소드당 중앙 1회·최대 1회**(히스테리시스 진입 8°·
이탈 11° 가 경계 깜빡임을 완전히 막음), 전환 패턴은 `left×59 → ahead×105` 꼴.
섹터 분포가 ahead 63 % / right 19 % / left 18 % 로 쏠리므로
`train_reasoning.py --sector-balance`(역빈도 표집)를 추가했다.

**분류기 함정:** 문장에서 섹터를 읽을 때 `left`/`right` 만 보면 Stanley 코퍼스의
"Cruise in the **left lane**" / "the **rightmost** lane" 40개가 방향 명령으로 오분류된다.
`lane`/`차선` 포함 문장을 먼저 제외해야 한다 — g5 의 task 130개 전수 확인: lane 포함 40개,
미포함 24개이고 그 24개가 정확히 `SECTOR_TEMPLATES` 다.

## 3. 첫 유효 측정: 음성, 그리고 미세조정이 베이스 능력을 파괴한다

`g5` = `packed_sec` 292 ep + Stanley 109 ep = **80,129 프레임**(어제 25,335 와 대조).
학습 로그가 `sector balance: {'left': 16450, 'ahead': 21417, 'right': 16927} of 80129` 로
섹터 54,794 + 차선 25,335 = 80,129 을 정확히 가른다.

| 런 | 베이스 | 데이터 | 지시한 쪽 | 95 % CI | p(우연 50 %) | 예측/시연 |
|---|---|---|---|---|---|---|
| `s2` | r26 | g5 + 프레임별 라벨 | 38/55 = 69 % | [56, 80] | 0.0032 | **0.04** |
| `s2n` | r26 | g5 + **상수 `Drive.`** | 41/55 = 75 % | [62, 84] | 0.0002 | **0.16** |

**Fisher 양측 p = 0.672 — 구별되지 않고 대조군이 더 높다.** 방향이 우연보다 유의한 것은
양쪽 모두이므로(물려받은 잔여 반응), **문장이 기여한다는 근거는 없다.**

### 미세조정이 파괴한다 (이번 문서의 핵심 발견)

| 체크포인트 | 학습 데이터 | 예측/시연 |
|---|---|---|
| **r26** (베이스) | 차선 주행만 | **0.82** |
| s1 / s0 | r26 + Stanley (섹터 미포함) | 0.86 / 1.02 |
| **s2 / s2n** | r26 + **섹터 292 ep** | **0.04 / 0.16** |
| b1 | r26 + 이름 문장 g1 | 0.06 |

goto 데이터로 10k step 미세조정하면 0.82 → 0.04 로 떨어진다. **상수 문장 런도 같이
떨어지므로 원인은 문장이 아니라 학습 자체다.** r50~r54 가 전부 실패한 이유도 이것으로
설명된다 — 목표 지정을 가르치려는 시도가 이미 있던 방향 반응을 덮어썼다.

### 학습 자체는 정상이었다

| step | `s2` action / ce | `s2n` action / ce |
|---|---|---|
| 200 | 0.036 / 8.16 | 0.038 / 8.16 |
| 4,200 | 0.036 / 0.396 | 0.043 / 0.373 |
| **10,000** | **0.027 / 0.304** | **0.029 / 0.296** |

CE 8.16 → 0.30 수렴(이전 런 범위 0.2~1.0), action 안정. **섹터 균형 가중이 주행을 해치지
않았다.** 그리고 **두 런의 손실 곡선이 거의 동일하다** — 문장이 상수인 런과 의미 있는 런이
구별되지 않는다는 또 하나의 증거다.

## 5. 범위 (vla-scope-guard)

- **지금까지 "정책이 지시 문장을 읽는다"는 근거는 없다.** 유일하게 유효한 대조 실험
  (`s2` vs `s2n`)이 p=0.672 로 실패했고, 그 이전 비교들은 학습 데이터가 잘못되어 무효다
- 오프라인에서 보이는 방향 반응은 **베이스 r26 의 차선 단어 학습에서 물려받은 것**이고,
  goto 미세조정은 그것을 파괴한다
- 코퍼스 지표(CMI 상한의 56 %, 균형 1.1×)는 **시연 데이터의 성질**이고 모델의 언어 사용에
  대한 근거가 아니다
- 정차는 측정 150 시행에서 **STRICT 0건**이다. 사용자 결정에 따라 브리지 기하 게이트로
  분리하며, 그것은 정책이 배운 행동이 아니다
- 지시는 열린 자연어가 아니다 — 학습 플릿 12종 중 시야 안 3개를 가리키는 **3지 이산 모드**다
