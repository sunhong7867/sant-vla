# L2: SmolVLA 안 16층 VLM 특징에 물체 정보가 남아 있는가 (2026-10-13 16:46)

이전: [L1](20261013_1633_l1-smolvlm2-object-knowledge.md) — 원본 SmolVLM2-500M(32층+LM 헤드)은 이름을 안다(30/37).
이 문서는 정책이 실제로 쓰는 **16층 특징**과, 미세조정(g5d)이 그것을 지웠는지를 잰다. L3(행동은 이름을 안 따름, b1 22/42 vs b0 23/42)는 이미 음성.

## 설정

- 모델 3개, 같은 파이프라인:
  - `hf` = HF SmolVLM2-500M 을 16층으로 자른 것
  - `base` = `smolvla_base` 의 VLM 가중치
  - `g5d` = 서버 `runs/course/navvla_reasoning_g5d/checkpoints/015000` 의 VLM 가중치
    (`freeze_vision_encoder: true`, `train_expert_only: false`)
- prefix 는 lerobot `embed_prefix` 를 따라 재현: `resize_with_pad` 512(0 패딩) → `x*2-1` → vision → connector → `×√d`,
  언어 `Target.` 임베딩 `×√d`, prefix 전체 양방향 어텐션, 텍스트층 16개. state 토큰은 넣지 않았다.
- 특징 = 이미지 토큰(64개) 평균, `hidden_states[k]`, k = 0(connector 출력) / 4 / 8 / 12 / 16.
- 이미지 864장: Fuel 썸네일 물체를 잘라 **정책 카메라 도로 프레임**(g5d 평가 프레임)에 붙였다.
  크기는 512 입력 기준 물체 높이 L ≈ 200 / M ≈ 80 / S ≈ 35 px, 종류·크기별 12장.
  - **학습 = 썸네일 시점 1 + P2 프레임, 평가 = 시점 3 + P3b 프레임**(못 본 시점·못 본 배경)
  - 10 종: 곰인형, 봉제 인형, 공룡(3 모델), 말, 로봇, 소화전, 쓰레기통, 의자, 바나나, 오렌지
  - 예시: `media/20261013_l2_composites.jpg`
- 프로브 = 표준화 + 다항 로지스틱 회귀(C 0.5). 대조 2개: 라벨 섞기, 픽셀 기준선(32×32 픽셀, 512-bin 색 히스토그램).
- 코드: `server/code/course/l2_vlm_layer_probe.py`, `l2_pixel_baseline.py`, `l2_per_class.py`. 원자료: `media/20261013_l2_result.json`.

**가중치 비교**

- 최다 클래스 비율이 0.25 인 이유: 공룡만 모델이 3개라 평가셋의 1/4 이다.

**종류별 (g5d h16 vs 색, L/M/S, 종류당 12장, 공룡 36장)**

- 색으로는 안 되는데 VLM 은 되는 것: 말 1.00/1.00/0.92(색 1.00/0.58/0.17), 공룡 S 0.61(색 0.22), 바나나 S 0.67(색 0.00), 봉제 인형 S 0.58(색 0.00).

- **표본이 작아 종류별 수치는 방향만 본다.**

## 해석

- **L2 양성.** 물체 정체는 정책이 실제로 쓰는 16층 특징에서 선형으로 읽힌다.
  - 큰 물체(L)는 색만으로도 거의 풀린다. 그래서 VLM 이 색 이상의 정보를 준다는 근거는 **M·S 크기**의 차이(+0.15 / +0.33)다.
- **미세조정이 지우지 않았다.**
  - g5d 는 `freeze_vision_encoder: true` 라 비전이 그대로고, 나머지 변화는 |Δw| ≤ 0.004 다.
  - "미세조정이 언어 반응을 뺀다"(r26 0.82 → s2 0.04)는 **물체 시각 정보 손실로 설명되지 않는다.** 남는 후보는 언어 토큰↔행동 경로다.
  - 단 v3y 계열은 `freeze_vision_encoder: false` 였으므로 이 결론은 g5d 에만 해당한다.
- 그러므로 **L1 양성 → L2 양성 → L3 음성**이다. 정보는 정책 안에 있는데 행동이 이름을 쓰지 않는다. 병목은 지식이 아니라 학습·구조다.
  이는 g1 CMI 0.743 b(데이터는 결백)와 같은 방향이다.

## 한계

1. **종류당 물체 인스턴스가 1개다**(공룡만 3개). 그래서 이 측정은 "같은 물체의 다른 시점·배경"으로의 일반화다. 범주 인식("처음 보는 곰인형")이 아니다.
2. 붙여 넣은 합성이다. 장면 조명·그림자·가림이 없다.
3. 배경 프레임에 원래 물체(꼬깔·봉제 인형·의자 등)가 섞여 있다. 라벨과 무관하게 무작위로 골랐으므로 편향이 아니라 잡음이다.
4. 우리가 학습시킨 프로브다. 정보가 **있다**는 뜻이지, 정책이 그 정보를 **단어와 연결**한다는 뜻이 아니다.
   단어↔이미지 연결(프로브 학습 없이 "teddy bear" 텍스트 토큰이 해당 이미지 토큰과 정렬되는가)은 아직 안 쟀다.
5. state 토큰을 뺐다. 이미지 토큰 특징은 prefix 안에서 state 에 영향을 받을 수 있다(SmolVLA 의 state 는 att_mask 1 이라 이미지 토큰이 state 를 보지 않는다 → 영향 없음으로 판단).
