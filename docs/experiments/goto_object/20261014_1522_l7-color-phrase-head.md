# L7 사전 등록: 위치 층이 "파란색 물체" 같은 색 문장으로 물체를 찾는가 (2026-10-14 15:22)

배경: 10-14 GUI 시험에서 "파란색 물체로 가봐"를 SmolVLA 모드가 거절했다. L5 위치 층은 물체 이름으로만 학습했고, 색은 꼬깔 이름("파란 꼬깔")에만 들어 있다.
"드럼통 = 파란색"을 코드에 적는 방법은 쓰지 않는다(물체가 무엇인지 안다는 전제, 10-13 사용자 지적). 대신 색 문장을 학습 질의로 넣는다.

질문: 색 단어를 **한 물체로만** 배운 뒤, 같은 색의 **다른 물체**도 그 색 문장으로 찾는가?

## 고정 (실행 전)

- 특징: L5 와 같은 얼어 있는 SmolVLA 16층 이미지 토큰(`feat.npy`, 24,508장), 같은 Head 구조, 같은 시험 에피소드 분할(md5 % 5 == 0).
- 색 문장 벡터: L5 와 같은 방식(`"Go to the {phrase}."` 안의 phrase 토큰 평균), phrase = `"<색> object"`.
- 색 표(학습 프레임에서 사람이 눈으로 확인, 모델 파일 색과 일치):
  - red: red cone, fire hydrant
  - blue: blue cone, barrel
  - black: chair, trash can
  - yellow: yellow cone / white: white cone / brown: box
  - 제외: barrier(옛 코퍼스에서 회색 뒷면), dog·horse(얼룩), green cone·자동차·사람·로봇·공룡(드묾)
- **홀드아웃 조합**(색 문장 학습에서 뺌, 이름 질의는 그대로 학습):
  - red → fire hydrant, blue → barrel, black → trash can
  - 학습에서는 홀드아웃 물체가 보이는 프레임의 그 색 질의를 통째로 뺀다("파란색 = 드럼통 아님"을 배우지 않게).
- 색 질의 정답: 그 색 물체가 화면에 정확히 하나면 그 위치, 하나도 없으면 "안 보임", 둘 이상이면 뺌. "안 보임" 질의는 30 %만 뽑는다.
- 이름 질의: head_name_all 과 같이 모든 이름(horse·blue cone 포함).
- 학습 6 epoch, 시드 0, 서버 GPU.

## 지표 (시험 에피소드만)

- E1 일반화: 홀드아웃 물체가 그 색 물체 중 유일하게 보이는 프레임에서 색 질의 → 5°(46 px) 안이고 "보임"이면 맞음. 색별로 잰다.
  우연 기준 = 그 프레임들의 1/(보이는 물체 수) 평균.
- E2 학습한 조합: 학습한 색 물체가 그 색 중 유일하게 보이는 프레임에서 같은 채점.
- E3 헛것: 그 색 물체가 하나도 안 보이는 프레임에서 "안 보임"이라고 답한 비율.
- E4 이름 정확도: L5 의 A(여러 물체 프레임, 이름 질의).

## 기각선

1. E2 < 90 % 또는 E4 < 95 % 이면 학습 설정이 잘못된 것 → 결론 없음.
2. 색별 E1 이 50 % 이상이고 우연 기준의 2배 이상이면 "그 색은 일반화됨". 3색 중 2색 미만이면 **"색 일반화 기각"**: 색 문장은 학습한 물체-색 조합에서만 된다고 쓴다.
3. E3 < 80 % 이면 색 질의가 없는 물체를 있다고 하므로 GUI 에 붙이지 않는다.
4. 1·3 을 통과하면 홀드아웃 없이 전부 학습한 시연용 헤드(`head_color_all.pt`)를 GUI 에 붙인다. 2 가 기각이면 시연 설명은 "학습한 색-물체 조합"으로 한다.

## 해석

- 얼린 SmolVLA 특징 위의 작은 층은 "색"을 따로 떼어 배우지 않는다. 문장-물체 쌍을 외운다. 새 조합(실제 트랙의 처음 보는 파란 물체)은 못 찾는다.
- 강의 서술: "색 문장도 학습한 조합은 99 % 찾지만, 학습에서 뺀 조합은 0 %. SmolVLA 단독은 '배운 것만', 처음 보는 것은 VLM 계층형."
