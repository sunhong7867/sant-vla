# 점 목표 원시 동작 — "가리킨 곳으로 가서 서기" 사전 등록 (2026-10-12 18:50)

학습 전에 적은 문서다. 기각선은 결과를 본 뒤 고치지 않는다.

## 0. 왜 이 실험인가

강좌 요구(교수님, 10-12 사용자 정정): **A, B 를 배운 뒤 A+B 가 아니라 C 가 나오는가.** 사용자 제안: 학습 =
"물체 앞에 가서 서기", 확인 = 미학습 물체(동그라미·네모·세모), "동그라미와 네모 사이로", "세모 왼쪽에",
"멸종한 생물로". 전역 좌표·포즈 금지(실제 트랙, 유아용 전동차). 물체를 **인지**해서 가야 한다.

지금까지 goto 는 전부 목표를 **이름 또는 섹터 단어**로 줬고 전부 음성이었다
(이름 접지 b1 22/42 = b0 23/42 [20261007_1010]; 섹터 s3 방향만 유의, 시연 기준 0/10 [20261010_0215]).
세 칸 방식은 세 모드만 배우므로 "사이"는 원리상 네 번째 모드라 나올 수 없다.

**가설 H.** goto 음성의 원인은 데이터 부족이 아니라 목표를 이름으로 준 것이다. 목표를 **연속량
[goal_bearing, goal_dist]** 로 주고 학습이 그 범위를 덮으면, 정책은 "벡터 쪽으로 조향해 서라" 하나를
배우고, "두 물체 사이"·"물체 왼쪽"은 범위 안의 다른 값이라 보간으로 된다.

증거: 같은 채널(v8g)이 정책에 들리는 것은 확인됐고(반사실 54×, [log/20260824_1106]), 도달 실패는
ring_goal 34 ep 의 라벨 오염 상태에서 났다([log/20260824_1138]). 오염을 고친 v8h 는 결과 미기록이고
체크포인트는 삭제됐다(10-12 확인) → P1 은 생략.
