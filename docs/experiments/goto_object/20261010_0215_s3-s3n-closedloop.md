# s3 / s3n 폐루프 SEC n=30 — 방향은 재현, 시연 기준은 0/10

- 측정: 2026-10-09 15:47 ~ 16:33 (`tools/s3_closedloop_resume.sh`, 15,000 step 체크포인트)
- 설계·배경: [g4 공백·s2 음성·s3 계획](20261008_2237_g4-void-s2-negative-s3-plan.md)

## 1. 결과

| | s3 (문장 있음) | s3n (`Drive.` 고정) |
|---|---|---|
| **시연 기준** 세 명령 → 세 물체 | **0/10** | **0/10** |
| 느슨한 success | 4/30 = 13.3 % | 8/30 = 26.7 % |
| **목표에 가장 가깝게 종료** | **15/30 = 50.0 %** | **4/30 = 13.3 %** |
| STRICT (정차까지) | 0/30 | 0/30 |
| 결과 분포 | TIMEOUT 23, STOPPED 4, COLLISION 3 | COLLISION 11, STOPPED 9, TIMEOUT 8, OFF_PLANE 2 |
| gap 중앙값 | −0.18 m (맞은 물체 정차 n=1) | nan (n=0) |

최근접 15/30 vs 4/30 → **Fisher 정확검정 p = 0.00479.**

## 2. 읽는 법

**방향 효과는 폐루프에서도 재현된다.** 문장을 주면 목표 쪽으로 끝나는 비율이 50 % 로
우연(33 %) 위이고, 문장을 없애면 13 % 로 우연 아래로 떨어진다. 오프라인 ratio (s3 0.06,
s3n 0.45) 와 질적으로 일치한다 — s3 는 **방향은 맞으나 소심**(TIMEOUT 23), s3n 은
**과감하나 무작위**(충돌 11).

그러나 **시연 기준은 양쪽 0/10 이다.** 교수님께 보여줄 수 있는 상태가 아니다.
느슨한 success 가 s3n 에서 더 높은 것은 "많이 움직이면 어쩌다 가까워진다"는 뜻이므로
성능 지표로 읽지 않는다.

## 3. 정차는 여전히 고장

STRICT 0/30 이 양쪽 모두. `goto-vlm-perceive-vla-drive` 결정대로 정차는 브리지 기하 게이트가
담당해야 한다. 코퍼스에 standoff 이내 프레임이 0 개이므로 정책이 배울 지지가 없다.

## 4. 0/10 을 정책 탓으로 돌릴 수 없다 — 서빙이 깨져 있다

| 항목 | s3 | s3n |
|---|---|---|
| 워치독 히트 | 38 회 / 29 시행 | 32 회 / 28 시행 |
| underrun 최대 | 100 % | 100 % |
| lat p90 중앙값 | 95 ms | 97 ms |

underrun 100 % 는 계획이 완전히 고갈된 구간이 있었다는 뜻이다. 계획해둔 **공짜 수정이
아직 적용되지 않았다**: `refill_at` 0.3 → 0.8, `max_speed` 2.25 → 1.2 (코퍼스 최대 1.90,
중앙 1.00 — 현재 설정은 분포 밖). 이걸 적용하기 전의 0/10 은 정책 능력의 측정이 아니다.
s3 의 TIMEOUT 23 은 `max_speed` 분포 밖 + 소심한 조향의 합산으로 설명 가능하다.
