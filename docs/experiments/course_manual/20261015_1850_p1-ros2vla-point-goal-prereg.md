## 기각선
1. **P < 14/20 → "ros2_vla 이식본은 학생 경로로 물체에 못 간다"**. 강좌 기준 모델로 쓰지 않는다.
2. P < 14 이고 PG ≥ 14 → 원인은 인지(goal_node) 쪽. PG < 14 → 정책(데이터·학습 설정·행동 공간) 쪽.
   PG 결과는 주장에 쓰지 않는다 (실차에는 좌표가 없다).

예상(적어 둠): PG 는 통과, P 는 g5s100 처럼 16~18/20. 다만 expert 만 학습하는 설정이 g5d 와 달라 정차 직전 조향이 흔들릴 수 있다.
