# 5. 실습 점검 (11-16 ~)

연구 검증 다음 단계: 학생이 실제로 할 실습이 처음부터 끝까지 되는지 본다.

- **온라인 실습 (시뮬):** 1 · 2차선 주행 + 차선변경.
- **오프라인 실습 (실제 트랙, 시뮬로 먼저 · 같은 코드):** 2차선 주행 + 물체 3 개 중 말한 물체 앞으로 (문장 두 개 방식 학습), 움직이는 물체 따라가기는 일반화 시험.
- 학생이 문장을 쓰고 수동주행으로 모음 → Colab 전체 학습 (SmolVLM2 + Expert) → 노트북에서 실행.
