## 2. 빈 차선 조건 버그

`avoidance_trial.py` 의 오라클이 장애물 모델이 `none`(빈 차선)이어도 가상 지점을 장애물로 보고 "ahead" 를 보냈다
(로그: `oracle: ahead (arc 13.5 m, lat +0.38)`). 그래서 빈 차선 20/20 차선 변경 — 이 수치는 **"문구만 듣고 물체 없이도
꺾는다"** 는 뜻으로만 읽을 수 있다(인지 분리형의 의도된 성질: 조향은 문구를 따른다).

- 수정: `ob_ours = ob0["lane"] == args.start_lane and ob0["model"] != "none"`.
- 무효 결과는 `eval_out/course/multiobj_eval/bad_oracle_empty/` 로 옮김.
- 재평가: `tools/r41or_empty_rerun.sh` — 다물체 짝 수집이 끝나면 빈 차선 20 곳만 자동(약 20 분).
- r40 의 이전 정답 문구 평가는 빈 차선 조건이 없었으므로 영향 없음.

## 3. 해석 (E2E 와 비교)

1. 같은 20 곳에서 **문구가 있으면 꺾는다(20/20), 없으면(r46) 반응 +0.27 m**. "언제 꺾나" 를 문구가 대신 정해 주면 조향
   자체는 이미 가능하다. E2E 의 병목은 조향이 아니라 **장애물을 보고 꺾을지 정하는 부분**이다.
2. 회피 성공률 45 % 는 타이밍·폭 문제다. 후보: 문구 "ahead" 시점을 13.5 m 보다 앞당기기(평가 설정), 또는 r48(문구 조건화 +
   다물체 짝)에서 회피 시연의 램프를 학습.
3. 단계 B(정답 문구 → VLM 판단)는 학습 물체·미학습 물체 비교 실습의 본체다. VLM 의 차선 귀속 문제(시뮬은 좌표로 판정)는
   그대로 남아 있다.
