# 관련 연구 정리 — 행동 복제의 지름길과 VLA 벤치마크 비판, 우리 연구의 위치 (2026-10-03 09:44)

관련: [지름길 학습 개념](20261002_1414_shortcut-learning.md) · [종합표](20261002_1354_avoidance-models-summary.md) · [r46](20261002_1857_r46-pair137-result.md) · [r47](20261003_0940_r47-multiobj-pairs-and-pilot.md)

## 0. 요약

- 지름길 문제(인과 혼동·카피캣)는 VLA 이전, **작은 MLP·CNN 정책을 행동 복제로 처음부터 학습**하던 시기(2018~2020)에 보고됐다.
- VLA도 학습 방식은 "대규모 사전학습 위의 행동 복제"라서 이 문제를 그대로 물려받는다. 2025년부터 이를 보여 주는 **VLA 벤치마크 비판 연구**가 나왔다.
  - LIBERO-PRO, LIBERO-Plus, LIBERO-X: 표준 점수 90 % 이상인 모델들이 위치나 지시문을 조금만 바꿔도 무너진다. 시연 궤적을 외우고 지시문은 무시한다.
- 이 비판들은 대부분 **로봇 팔 조작(LIBERO)**에서 **교란을 주는 방식**으로 평가한다.
- 우리 연구의 위치는 이렇다. 같은 문제를 **소형 VLA(SmolVLA, flow matching)의 폐루프 주행 회피**에서 다룬다.
  - **같은 자리 대조군(장애물 있음 / 옆 차선 / 없음)**으로 지름길을 드러낸다.
  - **고치는 방법(같은 자리 짝 시연, 물체 다양화, 인지 분리)**을 같은 20곳에서 정량 비교한다.

## 1. 고전 행동 복제(BC)의 지름길 — VLA 이전

세부 설명은 [지름길 학습 개념](20261002_1414_shortcut-learning.md)에 있다. 여기서는 모델과 시기만 정리한다.

| 연구                                               | 모델                                   | 환경                                | 현상                                                   | 해결책                                           |
| ------------------------------------------------ | ------------------------------------ | --------------------------------- | ---------------------------------------------------- | --------------------------------------------- |
| ChauffeurNet (Bansal et al., Waymo, 2018)        | CNN+RNN 중간 표현 주행 정책                  | 실주행 로그 + 시뮬                       | 과거 궤적 입력을 그대로 이어 그림(카피캣형)                            | 과거 궤적 드롭아웃, 교란 합성 시연                          |
| 인과 혼동 (de Haan, Jayaraman, Levine, NeurIPS 2019) | MLP(상태 입력) / 작은 CNN(이미지 입력), 처음부터 학습 | MountainCar, MuJoCo Hopper, Atari | 직전 행동이 보이는 입력을 주면 그걸 단서로 써서 폐루프 성능이 떨어짐("계기판 브레이크등") | 인과 그래프 후보 + 전문가 질의·보상으로 선택                    |
| BC 한계 (Codevilla et al., ICCV 2019)              | ResNet 기반 CILRS                      | CARLA                             | **관성 문제**: 속도 입력과 "멈춤"의 상관 → 정지하면 계속 정지              | 속도 예측 보조 과제(부분 완화)                            |
| 카피캣 (Wen et al., NeurIPS 2020)                   | MLP, 관측 이력 입력                        | MuJoCo(속도 제거한 부분 관측)              | 이력에서 직전 행동을 추론해 반복                                   | 적대적 학습으로 이전 행동 정보 제거 (후속: keyframe 가중, CARLA) |

공통점은 **시연 데이터에서 정답 행동과 늘 같이 나오는 쉬운 단서**를 배운다는 것이다. 학습 손실은 낮지만 폐루프에서 실패한다.

## 2. 주행 E2E 평가 비판 — "지표가 지름길을 못 잡는다"

| 연구 | 내용 |
|---|---|
| Is Ego Status All You Need? (Li et al., CVPR 2024, NVIDIA) | nuScenes 개루프 계획에서 **카메라 없이 자차 상태(속도·가속·요)만 쓰는 Ego-MLP**가 최신 E2E 모델과 비슷한 점수를 냄. 모델들도 실제로는 자차 상태에 기대고 있었음. 개루프 지표로는 지름길이 안 보인다는 비판 |
| AD-MLP (Zhai et al., 2023) | 같은 문제를 먼저 지적. 자차 상태 MLP로 nuScenes 개루프 최고 수준 |

우리와의 연결: 개루프 손실이나 단일 조건 성공률로는 sw80 같은 "잘 피하는 것처럼 보이는" 모델을 거를 수 없었다. 우리는 **폐루프 + 대조군**으로 걸렀다.

## 3. VLA 벤치마크 비판 (2025~2026)

### 3-1. LIBERO-PRO (Zhou et al., arXiv 2510.03827, 2025-10)

- **대상**: OpenVLA, π0, π0.5
- **방법**: 표준 LIBERO에 네 가지 교란을 준다. 조작 물체(속성), 초기 상태(위치), 지시문(의미), 환경.
- **결과**:
  - 표준 평가는 90 % 이상이지만, 일반화 설정에서는 **0 %까지 무너진다**(π0.5는 일부 과제 0.38).
  - 물체 위치를 0.2 단위 이상 옮기면 OpenVLA·π0은 성공률 0이 된다. π0.5는 0.4까지 버틴다.
  - 지시문을 "fdsgfdsgsd", "xxxx" 같은 무의미 문자열로 바꿔도 **같은 행동 시퀀스를 낸다**.
  - 대상 물체를 바꿔도 원래 물체를 잡으러 간다.
- **결론**: 모델은 과제 이해나 환경 인지가 아니라 **학습 세트의 행동 시퀀스와 배치를 암기**한다.

### 3-2. LIBERO-Plus (Fei et al., arXiv 2510.13626, 2025-10, OpenMOSS)

- **대상**: 10개 모델. OpenVLA, OpenVLA-OFT(변형 3종), π0, π0-fast, Nora, WorldVLA, UniVLA, RIPT-VLA.
- **방법**: 7개 축 교란. 물체 배치, 카메라 시점, 로봇 초기 상태, 지시문, 조명, 배경 질감, 센서 노이즈.
- **결과**:
  - 카메라 시점과 로봇 초기 상태에 가장 약하다. 작은 교란에도 95 % → 30 % 아래로 떨어진다(하락폭 31~91 %p).
  - 배경 질감에는 비교적 강하다(2~15 %p).
  - 지시문 교란에 따른 하락은 14~34 %p로 작다. 그런데 이건 강해서가 아니라 **지시문을 안 보기 때문**이다.
    - 지시문을 비워도 OpenVLA-OFT의 성능이 거의 그대로였다.
    - 목표 물체 이름을 바꾸면 성공률이 거의 0이었다. 원래 행동을 계속했기 때문이다.
- **완화**: 교란된 궤적 2만 개 이상을 섞어 미세조정하자 카메라 55.6 % → 92.8 %, 전체 79.6 %로 올랐다. 즉 **데이터 다양화로 상당 부분 회복**된다.

### 3-3. LIBERO-X (Wang et al., arXiv 2602.06556, 2026-02)

- 공간 이해, 물체 식별, 과제 이해를 단계별로 어렵게 하는 평가 프로토콜이다.
- 한 장면에 여러 목표가 있는 원격 조종 학습 데이터를 함께 제공한다.
- 교란이 누적되면 성능이 크게 떨어진다. 약점은 **장면 이해와 지시문 접지**로 지목된다.

### 3-4. 해결 쪽 연구 — DILL (Kim et al., arXiv 2609.37165, 2026-09, 서울대 장병탁 교수팀 포함)

- **문제 정의**: VLA는 과제 구조가 아니라 **도메인 고유 요인과의 허위 상관(spurious correlation)**에 기댄다.
- **방법**: 과제·도메인 인코더를 대조 학습과 분리 정규화로 학습한다. 정책이 미래 잠재 표현을 예측하도록 감독한다.
- **결과**: LIBERO-Plus 평균 69.1 %로, 최강 기준선보다 11.4 %p 높다.
- **평가**: "반사실 과제-시점 평가"로 지름길 의존도를 측정한다. 우리 대조군 평가와 개념이 가깝다.

### 3-5. 그 밖

- "instruction blindness" 표현이 2026년 논문들에서 쓰인다(예: Stable Language Guidance for VLA, arXiv 2601.04052).
  - 고빈도 시각 신호가 드문 언어 토큰을 압도한다는 설명이다.

## 4. 우리 결과를 같은 틀로 보면

### 4-1. 대응 관계

| 비판 연구의 발견 | 우리 실험에서 나타난 모양 |
|---|---|
| 배치·궤적 암기 (LIBERO-PRO 위치 교란) | **트랙 자리 지름길**: sw80은 회피 7/8이었지만 빈 차선 같은 자리에서도 2.26 m 꺾었다. r44는 빈 차선 10/20. 출발 거리를 바꿔도 같은 자리에서 꺾었다(1414 문서 4-1절) |
| 지시문 무시 | 인지 분리형에서 문구가 실제로 쓰이는지 따로 확인했다: r41 + 정답 문구 → 우리 차선 차선 변경 20/20, 옆 차선 유지 20/20, 빈 차선 0/20(문구가 행동을 바꿈) |
| 데이터 다양화로 회복 (LIBERO-Plus) | 같은 자리 직진 짝을 늘리자 **지름길 없이** 장애물 반응이 자랐다. r45(짝 60) +0.10 m → r46(짝 137) +0.27 m. 다만 차선 변경(약 1.8 m)에는 크게 못 미친다 |
| 새 단서가 생김 | r47(물체 5종, 짝 286): 반응이 +0.14 m로 줄었다. 대신 **장애물과 무관한 왼쪽 쏠림 1.1 m**가 생겼다. 시연이 전부 "2차선 출발·왼쪽 회피"라 방향 자체를 배웠다 |

마지막 행은 짝 시연이 한 단서(자리)를 막아도 **시연에 남은 다른 공통점(방향)**이 새 지름길이 됨을 보여 준다. 그래서 다장애물 수집(1·2차선 출발, 양방향, 꺾는 거리·폭 무작위)으로 바꿨다(2106 문서).

### 4-2. 평가 방식의 차이

|        | LIBERO 비판 연구             | 우리                                                          |
| ------ | ------------------------ | ----------------------------------------------------------- |
| 과제     | 로봇 팔 조작, 성공/실패           | 주행 회피, 폐루프                                                  |
| 지름길 검출 | 교란 후 성공률 하락              | **같은 자리 반사실 대조군**: 장애물 있음 / 옆 차선 / 없음, 짝 차이(있음 − 없음)의 신뢰 구간 |
| 모델     | 대형 VLA(OpenVLA 7B, π0 등) | 소형 VLA(SmolVLA 450M), 노트북 + 3090 1장                         |
| 해결     | 다양화 미세조정, 표현 분리(DILL)    | 짝 시연 수, 물체 수, 시연 다양성, 인지 분리를 같은 20곳에서 통제 비교                 |

### 4-3. flow matching과 지름길 — 가설 상태

- **원래 가설**: MSE 정책은 지름길에 걸리면 "반쯤 꺾기"(평균)를 낸다. flow matching 정책은 "꺾거나 직진"을 확률적으로 고른다.
  - 근거: r44 빈 차선 10/20.
- **반대 증거**: r45·r46·r47에서는 빈 차선 차선 변경 0/20이다. 장애물 반응도 평균 이동(+0.1~0.3 m) 꼴로 나왔다. 이분된 선택이라기보다 **작은 평균 이동**에 가깝다.
- **판정 방법**: 같은 자리를 여러 번(예: 10회) 반복해서 최대 횡 오프셋 분포가 두 봉우리인지 본다. 확인 전에는 기여로 내세우지 않는다.

## 5. 기여 후보 (확인 필요 사항 포함)

1. **폐루프 반사실 대조군 평가 프로토콜** — 가장 강함
   - 단일 조건 성공률로는 안 보이던 자리 지름길을 같은 자리 대조군으로 검출했다(sw80, r44).
   - LIBERO 비판 연구와 같은 문제의식을 **주행·폐루프·짝 차이 통계**로 구현한 것이다.
2. **짝 시연의 정량 효과와 남은 지름길**
   - 짝 수 → 반응 크기(r45 → r46)를 쟀다. 물체 다양화가 방향 지름길을 새로 만든 것(r47)도 보였다.
   - "한 단서를 막으면 다음 공통점이 단서가 된다"는 연쇄를 같은 20곳에서 보였다.
3. **E2E 대 인지 분리형의 통제 비교**
   - 같은 차, 트랙, 20곳에서 비교했다. 현재 인지 분리형(정답 문구)은 "언제 꺾나"를 해결하고(차선 변경 20/20), 남은 문제는 꺾는 시점과 깊이다(회피 9/20).
   - E2E의 병목은 조향이 아니라 "언제 꺾나"라는 점이 분리됐다.
4. **소형·저자원 재현성과 실제 트랙 이전** — 단독 기여로는 약하다. 강좌 실습과 직결된다.

확인할 것:
- 주행 VLA(EMMA, OpenDriveVLA, AutoVLA, ORION 등)에서 **폐루프 반사실 대조군**으로 지름길을 보고한 연구가 있는지.
- 반사실 짝 시연(counterfactual paired demonstrations)을 VLA 미세조정에 쓴 연구가 있는지.
- flow matching이나 diffusion 정책의 인과 혼동을 다룬 연구가 있는지.
