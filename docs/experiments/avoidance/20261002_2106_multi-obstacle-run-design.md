# 다장애물 주행 수집 설계 — 1·2차선 출발, 한 바퀴 장애물 3 개, 사람 같은 꺾기 (2026-10-02 21:06)

## 배경

- r45(짝 60)·r46(짝 137) 모두 회피 0/20, 빈 차선 0/20. 장애물 반응은 짝 수에 따라 +0.10 → +0.27 m 로 자라지만 1.8 m 에는 부족
  ([20261002_1857](20261002_1857_r46-pair137-result.md)).
- 같은 시뮬에서 선배(E2E·월드 모델 연구)가 같은 문제를 겪었고 **장애물을 1·2차선 곳곳에 두고** 학습해 해결. 주행 자체는 수동 2~3 바퀴로 충분했다고 함.
- **사용자 결정 (21시)**: E2E 로만 간다. 인지 분리형(VLM → 문구 → 조향)은 "인지 후 회피" 라 교수님 요구("학습 안 한 물체 회피")에 맞지 않음.
- 지금까지 데이터 집계(packed_boxtri/boxpair/boxpair2/mpair 계획): **내 차는 전부 2차선 출발, 회피는 전부 왼쪽, 옆 차선 장애물은 전부 왼쪽(1차선),
  에피소드당 장애물 1 개, 20~30 m 앞 정지 출발.** "출발하면 언젠가 왼쪽으로" 라는 지름길이 남을 수 있는 구성.

라벨: `label_reasoning.py` 가 프레임마다 "아직 8 m 이상 지나치지 않은 가장 가까운 장애물" 을 골라 기존 문장 규칙으로 서술.
옛 단일 장애물 데이터는 라벨이 바이트 단위로 같음을 확인(packed_boxpair2 6 ep).

## 평가 추가

`stat_eval.sh` 조건: `ours1 / adj1 / empty1 / held1` = 1차선 출발(오른쪽으로 회피). `stat_analyze.py` 는 1차선 조건의 횡 오프셋 부호를
뒤집어 "회피 방향 = +" 로 맞춘다(1차선은 2차선 기준 +3.15 m 왼쪽, 확인).
미학습 물체: `held`(사람), `heldcar`(초록 차).
