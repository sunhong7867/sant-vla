## 1. E2E 트랙 — "장애물이 있을 때만 꺾기" 학습

**원칙** (r38~r45에서 얻은 것):
1. **모든 회피(v1)에는 같은 출발·같은 자리의 직진 쌍(v2 또는 v0)이 있다.** 짝 없는 v1은 넣지 않는다.
   - r44가 반례다. 짝 없는 v1이 자리 지름길을 다시 만든다.
2. 가중 후 v1 표본 비중은 40~50 %로 한다. 학습 로그의 `sampled share by variant`로 확인한다.
3. 물체를 여러 종 쓴다. 그래야 "박스 무늬"가 아니라 "우리 차선의 무언가"를 배우게 할 수 있다.
4. 판정은 반드시 3조건(우리 차선 / 옆 차선 / 빈 차선)으로 한다.

**R1 — 박스 짝 수 늘리기 (오늘~내일)**
- 17:30에 r45(60쌍) 결과가 나온다.
- 동시에 정리 직후 packed_boxpair2를 서버로 보낸다.
  - **v46r** = v45r + boxpair2(약 137쌍).
  - **r46**은 **GPU0**(현재 비어 있음)에서 바로 학습한다. 8000 step, 약 1 h.
  - 스크립트: `convert_v45r.sh`, `launch_r45.sh`를 복제해 v46r·r46으로 만든다. 기존 `tools/r45_chain.sh`의 대기·평가 구조를 재사용한다.
- r46 평가: r45 평가가 끝나면 같은 20곳에서 평가한다(seed 20261002, `stat_eval.sh` + `stat_analyze.py`).
- 같은 20곳의 r43 → r44 → r45 → r46 표를 만들면 **짝 수에 따른 경향**이 나온다.

**판정 G1** (r46 기준, 20곳):
- **통과**: 빈 차선 차선 변경 ≤ 2/20, 옆 차선 차선 변경 ≤ 2/20, 그리고 회피가 r43(0/20)보다 확실히 많다(≥ 6/20).
  - → R2로 간다.
- **회피가 짝 수에 따라 오르지만 아직 낮음**: 빈 차선은 깨끗한 경우다.
  - → R2에서 짝을 더 모으면서 다물체로 간다.
- **짝을 늘렸는데 빈 차선 꺾기가 돌아옴**: 이 설정에서 E2E는 한계다.
  - → E2E는 "지름길 학습 사례"로 실습에 쓴다. 남은 시간은 인지 분리형에 쓴다.

**R2 — 다물체 짝 수집 → r47 (3~6일차)**
- 수집은 기존 `tools/collect_multiobj_avoid.sh`를 쓴다(train/heldout 플릿을 이미 지원한다).
  - TRAIN_MODELS = `ob_box, ob_barrel, ob_cone, ob_barrier, hatchback_red`
  - HELDOUT_MODELS = `ob_person, hatchback_green`
  - `OB_VARIANTS=v1,v2`(짝), `POSE_SOURCE=cli`. 그룹마다 물체 1종이고 위치는 무작위다.
- 규모는 약 160묶음(320 ep)이고 밤새 약 5 h 걸린다. 수집 중에만 performance 프로필을 쓰고, 끝나면 balanced로 되돌린다.
  - holdout 물체는 평가용으로만 수집하거나 생성만 한다.
- r47 = 박스 짝 137쌍 + 다물체 짝 약 150쌍 + 기존 v0.
- 평가는 20곳 × 4조건이다.
  - 조건: 학습 물체(우리 차선) / **미학습 물체(우리 차선)** / 옆 차선 / 빈 차선.
  - `stat_eval.sh`에 미학습 물체 조건을 추가한다(avoidance_trial `--models`).

**R3 — 여유 1회 (7~10일차)**
- R2 결과에 따라 짝 추가 또는 레시피 조정을 1회 더 한다. 강좌용 모델을 확정한다.

## 2. 인지 분리형 트랙 (병행, 학습 거의 없음)

- 조향 모델은 **r41**(위치 무작위 + 옆 차선 직진 + 상황 문구로 학습)을 쓴다.
  - 정답 문구 조건에서는 옆 차선 유지 8/8, 회피 2/4(2곳만 평가)였다.
- 단계 A: 오라클 문구(`avoidance_trial --oracle-situation`)를 주고 R1과 **같은 20곳 × 3조건**에서 평가한다.
  - 목적은 "들으면 피하는가"를 제대로 재는 것이다.
  - 회피가 낮게 나오면 r41 레시피에 다물체 짝 데이터를 더해 r48(문구 조건화)로 다시 학습한다.
- 단계 B: 오라클을 VLM 판단으로 바꾼다.
  - 기존 `chat_gui_node._avoid_check`(qwen2.5vl 목격) 또는 서버 `--situation-from-reasoning` 경로를 재사용한다.
  - 학습 물체와 미학습 물체(사람, 초록 차)에서 비교한다.
  - 알려진 제약: VLM은 차선 귀속을 못 했다(전부 same/left로 붕괴). 시뮬에서는 좌표로 판정한다.
  - **실제 트랙에서 차선 판정을 어떻게 할지는 미결**이다. 후보는 화면 내 위치 규칙, 라이다 외부 측위다. 시뮬이 끝난 뒤 결정한다.

## 3. 강좌 실습 초안 (두 방식 비교)

| | E2E | 인지 분리형 |
|---|---|---|
| 학습 | 물체 5종 짝 시연 | 차선 변경 + 문구 |
| 학습 물체 | 회피? | 회피? |
| 미학습 물체 | **회피하는가 = 실습 질문** | VLM이 알아보면 회피 |
| 빈 차선 대조 | 지름길 시연 (sw80 vs r43) | 문구 없으면 유지 |

- 미학습 물체를 각 방식이 **어디서** 처리하는지(행동 일반화 vs 인지 일반화) 대비하는 것이 핵심이다.
- E2E가 실패하더라도 실습은 성립한다.
