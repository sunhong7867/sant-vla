# 자율주행 VLA vs 연구실 YOLO 주행 — 무엇이 다른가 (2026-10-03 11:51)

단기강좌 실습 정하기([실습 정하기.md](실습%20정하기.md))용 정리. 교수님 질문 "일반 주행도 YOLO로 주행하는 거랑 다를 게 뭐냐"에
답하기 위한 문서다. 숫자는 이 저장소에서 측정한 것만 쓰고, 측정 안 한 것은 "미확인"으로 표시했다.

---

## 1. 두 스택의 실제 구조 (우리 연구실 기준)

### YOLO 주행 스택 (H-mobility 수업 코드 출발, 실차 VLA_AD 도 같은 골격)

```
카메라 30 Hz → YOLO 세그멘테이션 (camera_perception_pkg)
            → 차선 BEV → 2차 다항식 x = f(y)
            → motion_planner: 룩어헤드 + pure pursuit 로 조향 계산 (decision_making_pkg)
            → MotionCommand → 시리얼
  (+ 라이다 처리 lidar_perception_pkg, 실차 VLA_AD 는 Qwen3-VL 이 속도 배율만 조정)
```

- 행동을 정하는 것: **사람이 짠 규칙과 제어식**. 학습된 부분은 "차선이 어디 있나"(인지)뿐이다.

### VLA 스택 (nav-vla, SmolVLA 약 450M)

```
카메라 픽셀 + 명령 문장 + 차량 상태 [속도, 요레이트, 조향각]
            → SmolVLA 정책 서버 → 약 3 초 분량 행동 청크(30 스텝)
            → 브리지 → /cmd_vel
  (자유 문장은 chat_gui 의 파서가 학습된 정본 문장으로 변환해서 전달)
```

- 행동을 정하는 것: **시연 데이터로 학습된 하나의 모델**. 인지·판단·제어 모듈이 따로 없다.
- 확인 질문 하나로 성격이 갈린다: **모델을 빼면 VLA 스택은 차가 안 가고, VLA_AD(YOLO+pure pursuit)는 그대로 간다.**
  ([ver2/navvla_vs_vlaad_comparison.md](../experiments/log_thor/navvla_vs_vlaad_comparison.md))

## 2. 차별점 — 근거 수준별

| 차별점 | VLA | YOLO 스택 | 우리 근거 |
|---|---|---|---|
| **같은 영상, 다른 말 → 다른 행동** | 명령 문장이 모델 입력이라, 같은 출발에서 차선·속도가 달라진다 | 명령을 받을 입력이 없음. 바꾸려면 코드·파라미터 수정 | **확인**: 학습된 표현 문장 쌍의 궤적이 +2.51 m 갈라짐 (같은 문장 반복은 +0.05 m). 차선·속도 반사실 쌍 분리가 잡음 바닥의 20~27 배 (v3y) |
| **새 행동을 코드 대신 시연으로 추가** | 시연 + 문장을 모아 다시 학습 | 행동마다 규칙·제어 코드 추가 | **확인**: 차선·속도(v3y) → 존 목적지·순항(v8 계열) → 차선 변경(r33~) 을 모두 데이터 수집으로 추가해 왔음 |
| **행동 이유를 말로 출력** | 같은 모델이 주행하면서 상황 서술 문장을 냄 | 없음 (로그만) | **확인(부분)**: r1 학습 제외 에피소드에서 고유 문장 37/40, 서술의 차선 정확 68 %·속도 69 %. 서술과 조향이 따로 노는 경우가 있음 (회피 실험에서 물체 이름은 맞혀도 조향은 반응 없음) |
| **사전학습 지식으로 대상 지정** ("빨간 차 앞에서 멈춰") | 이론상 가능 — VLM 이 단어와 그림의 연결을 이미 가짐 | 클래스·규칙 추가 필요 | **미확인** — 실습 후보 2번. 아직 시험 안 함 |
| **학습 안 한 표현 따르기** | 큰 모델은 됨 (RT-2 등) | 해당 없음 | **우리 정책은 실패**: 뜻이 같은 처음 보는 표현은 +0.36 / +0.06 m, 주차 0/8 (A3). 그래서 파서가 정본 문장으로 바꿔 줌 |

정리하면 **지금 확실히 말할 수 있는 VLA 차별점은 "언어로 행동 전환"과 "시연으로 행동 추가" 두 가지**이고,
"설명 출력"은 부분적으로, "사전학습 지식 활용"은 아직 미확인이다.

## 3. YOLO 스택이 더 나은 점 (같이 말해야 하는 것)

| 항목 | YOLO 스택 | VLA |
|---|---|---|
| 차선 중앙 정밀도 | 정의상 기준선 (선생) | 선생을 모방해 0.19~0.26 m 안 (v3y) — 선생보다 좋다고 할 근거 없음 |
| 예측 가능성·디버깅 | 어느 모듈이 틀렸는지 보임 | 블랙박스. 지름길 학습(아래 4절)이 생겨도 겉으로 안 보임 |
| 안전 검증 | 규칙 단위로 검증 가능 | 보장 없음 — 실차엔 라이다 근접 정지 같은 규칙 안전층 필수 |
| 데이터 | 인지 학습용 라벨만 | 행동 시연 수백 에피소드 |
| 속도 | 50 Hz 제어 | 정책 재추론 약 10 Hz, 행동 청크로 버팀 |
| 처음 보는 물체 **피하기** | 라이다로 "무언가 있다"만 알면 됨 | 시연 분포에 의존 (우리 실험 0/20) |

**마지막 줄이 교수님 지적의 핵심이다.** 장애물 회피는 라이다·YOLO 규칙으로 되기 때문에 VLA 만의 실습이 될 수 없다.

---

## 4. 회피 실험(r38~r47)이 알려준 것 — "행동은 규칙이 아니라 데이터에서 온다"

- 회피 시연을 늘리면 빈 차선에서도 같은 자리에서 꺾었다(스윕 sw80: 2.3 m). 같은 자리 직진 짝을 넣으면 그 습관은 사라졌지만 회피도 약해졌다(r43~r47).
- 모든 회피가 왼쪽이었더니 장애물과 무관하게 왼쪽으로 1 m 쏠렸다(r47).
- YOLO 규칙에서는 생길 수 없는 실수다. **VLA 의 약점이자, 학생에게 "데이터가 행동을 정한다"를 보여 주는 가장 좋은 재료**다.
  (r40 체크포인트: 한 자리에서만 배워 옆 차선 박스에도 같은 자리에서 꺾음 — 서버에 남아 있음)

## 5. 실습에서 보여 줄 차별점 (1 시간 기준)

| 순서 | 보여 줄 것 | YOLO 로는 안 되는 이유 | 준비 상태 |
|---|---|---|---|
| ① | 같은 출발에서 "안쪽 차선 천천히" vs "바깥 차선 빠르게" | 명령 입력이 없음 | 모델 있음 (r26/v3y) |
| ② | 고정 카메라 한 장면 + 명령만 바꿔 행동 계획(궤적) 비교 | 같은 입력이면 같은 출력 | 프로브 스크립트 일부 있음, 학생용 정리 필요 |
| ③ | 주행 중 모델의 상황 서술 문장 표시 | 서술 기능 없음 | 있음 (서술 정확도 한계 함께 표시) |
| ④ | 말로 지정한 물체 앞에서 멈추기 — 학습 안 한 물체 포함 | 클래스·규칙 추가 필요 | **미확인, 시뮬 시험 필요** (실습 후보 2번) |
| ⑤ | r40 vs r41: 같은 장면, 다른 데이터 → 다른 습관 | 규칙엔 습관이 없음 | 체크포인트 있음 |

## 6. 발표·자료 문장

| 피할 표현 | 쓸 표현 |
|---|---|
| "VLA 가 명령을 이해해서 주행한다" | "명령 문장이 모델 입력이라, 같은 영상에서도 문장에 따라 차선·속도가 달라진다 (2 차선 × 3 속도 등 학습한 정본 문장 기준)" |
| "자유롭게 말로 시킬 수 있다" | "자유 문장은 파서가 학습된 정본 문장으로 바꿔 전달한다. 정책 자체는 처음 보는 표현을 따르지 못했다 (A3)" |
| "VLA 가 YOLO 보다 잘 달린다" | "차선 정밀도는 YOLO 선생 쪽이 기준이다. VLA 의 차이는 정밀도가 아니라 행동을 말과 데이터로 바꾼다는 점이다" |
| "모델이 이유를 설명한다" | "모델이 주행과 함께 상황 서술 문장을 낸다. 서술이 실제 조향 근거라는 보장은 없다" |
| "처음 보는 물체도 피한다" | "물체 회피는 라이다 규칙으로도 된다. VLA 고유 영역은 말로 대상을 지정하는 쪽이며 우리 모델에서는 아직 시험 전이다" |
