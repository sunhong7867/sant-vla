# VLA 최근 연구 동향과 장점 — 로봇·자율주행 (2026-10-03 11:51)

단기강좌 개념 파트용. "사람들이 왜 VLA·월드 모델을 계속 연구하는가"에 답한다. 각 장점 옆에 **어느 논문이 무엇을 보였는지**를 붙였고,
수치는 원 논문·공식 발표 기준이다(출처는 맨 아래). 강의 슬라이드에 수치를 옮길 때는 원문을 한 번 더 확인할 것.

---

## 1. 한 줄 정의

**VLA (Vision-Language-Action)** = 인터넷 규모 그림·글로 사전학습된 VLM 에 행동 출력을 붙여, 로봇·차량 시연 데이터로 추가 학습한 모델.
**사전학습이 "무엇이 무엇인지"를, 시연이 "어떻게 움직이는지"를, 언어가 둘을 잇는다.**

**월드 모델** = "이렇게 움직이면 다음 장면이 어떻게 될지"를 예측·생성하는 모델. VLA(무엇을 할지 고르는 정책)와 보완 관계다.

---

## 2. 흐름 (주요 작업만)

### 로봇 일반

| 연도 | 모델 | 의미 |
|---|---|---|
| 2023 | **RT-2** (Google DeepMind) | VLM 을 웹 데이터 + 로봇 데이터로 함께 학습. 로봇 데이터에 없던 기호·사람 인식·관계("X 를 Y 근처로")를 따르는 **창발 능력** 보고. 동시에 **새 동작은 로봇 데이터 범위를 못 넘는다**고 한계 명시 |
| 2024 | **OpenVLA** (7B, 공개) | 대규모 공개 로봇 데이터(Open X-Embodiment)로 학습한 오픈소스 VLA |
| 2024 | **π0** (Physical Intelligence) | VLM + flow matching 행동 전문가 구조. 우리 SmolVLA 와 같은 계열 |
| 2025 | **π0.5** | 학습에 없던 **새 집**(샌프란시스코 임대 주택 3 곳)에서 청소 등 가정 과제 수행 — "열린 세계 일반화" |
| 2025 | **SmolVLA** (Hugging Face, 약 450M) | 커뮤니티 공개 데이터로 학습한 소형 VLA. **우리 연구의 기반 모델** |

### 자율주행

| 연도 | 모델 | 의미 |
|---|---|---|
| 2019 | **Talk2Car** | nuScenes 위에 "저 차 뒤에 세워" 같은 **물체 지칭 명령** 데이터셋. 말로 대상을 고르는 문제의 출발점 |
| 2024 | **LMDrive** (CVPR) | 언어 지시를 받는 **폐루프** E2E 주행(CARLA), 약 6.4 만 클립 데이터 + LangAuto 벤치마크 |
| 2024 | **Wayve LINGO-2** | **공공도로에서 시험한 첫 폐루프 VLA 주행 모델**. 주행하면서 판단을 말로 실황 설명, "갓길에 세워" 같은 제한된 명령 수행 |
| 2024 | **DriveVLM / DriveVLM-Dual** (칭화대·Li Auto) | VLM 의 단계별 추론으로 **긴 꼬리 상황** 대응, 기존 모듈과 합친 이중 구조로 양산 차 하드웨어에서 평균 410 ms 비동기 동작 |
| 2024 | **Waymo EMMA** | Gemini 기반. 카메라 → 경로·물체·도로 그래프를 모두 텍스트로 출력. 과제를 함께 학습하면 각각 따로보다 좋아지는 **양의 전이** 보고 |
| 2025 | **SimLingo** (CVPR, CARLA) | 카메라만으로 CARLA 리더보드 2.0·Bench2Drive 1 위(CARLA Challenge 2024 우승). 주행 + 질의응답 + 지시 따르기를 한 모델로. **"Action Dreaming"**: 같은 장면에 여러 지시와 궤적을 붙여 말과 행동이 맞는지 평가 — 합성 지시 시험 81 % |
| 2025 | **NVIDIA Alpamayo-R1** | 인과 추론(Chain of Causation)을 거쳐 궤적을 내는 공개 VLA. 어려운 사례 계획 정확도 최대 12 % 향상, 폐루프 시뮬 근접 조우 35 % 감소, RL 후 **추론-행동 일치** 37 % 향상 |
| 2025 | **Wayve GAIA-2** (월드 모델) | 다중 카메라 주행 영상 생성. 흔한 장면과 **드문 장면을 합성**해 학습 데이터·안전 평가에 사용 |

## 3. 연구자들이 말하는 VLA 의 장점

| 장점 | 내용 | 근거 작업 |
|---|---|---|
| **1. 사전학습 지식 전이** | 로봇·주행 데이터에 없던 물체·기호·개념을 인터넷 지식으로 다룸 | RT-2 (기호, 사람 인식, 관계, "가장 작은 것") |
| **2. 언어로 과제 지정** | 한 모델이 명령에 따라 여러 행동. 과제마다 모델·코드를 따로 만들 필요가 줄어듦 | LMDrive, LINGO-2, SimLingo |
| **3. 설명 가능성** | 행동과 함께 판단을 말로 냄 → 사고 후 원인 분석, 승객 신뢰 | LINGO-2 실황 설명, Alpamayo-R1 추론 기록 |
| **4. 긴 꼬리(드문 상황) 대응** | 규칙으로 다 못 적는 드문 상황을 의미 수준에서 해석 | DriveVLM, Alpamayo-R1 |
| **5. 다과제 시너지** | 인지·예측·계획을 한 모델로 학습하면 서로 도움 | EMMA |
| **6. 새 환경 일반화** | 데이터 다양성 + 사전학습으로 처음 가는 장소에서도 동작 | π0.5 |
| **7. 데이터로 확장** | 새 능력 = 새 데이터. 손으로 규칙을 쌓는 비용 감소 | 분야 공통 동기 |

월드 모델은 4·6·7 을 데이터 쪽에서 돕는다: 드문 장면을 생성해 학습·평가에 쓰고(GAIA-2), 결과 예측으로 계획을 보조한다.

## 4. 같이 가르쳐야 하는 공통 한계

| 한계 | 내용 | 근거 |
|---|---|---|
| **새 동작은 못 만든다** | 의미(무엇을·어디로)는 넓어지지만 움직임은 시연 범위 안 | RT-2 논문 명시. 우리 역방향 주행 실험(시계방향 시연 0 건 → 좌회전만 하다 이탈) |
| **느리다** | 큰 모델일수록 추론 지연 → 빠른 모듈과 느린 VLM 을 나누는 이중 구조가 나옴 | DriveVLM-Dual 410 ms |
| **안전 보장이 없다** | 그래서 규칙 기반 안전층을 함께 둠 | 업계 공통. 우리 강좌도 라이다 근접 정지 |
| **데이터를 많이 먹는다** | 드문 행동은 시연이 적어 잘 안 배워짐 | 우리 r11: 약 20 개 클린 시연으로 정지 행동 미획득 |
| **지름길 학습** | 데이터에 우연히 함께 나온 단서로 행동 | 우리 r38~r47 회피 실험 (자리 습관, 왼쪽 쏠림) |
| **말과 행동이 어긋날 수 있다** | 설명은 그럴듯한데 행동은 다름 | Alpamayo-R1 이 "추론-행동 일치"를 따로 학습시킨 이유. 우리 회피 실험에서도 서술은 물체를 맞히고 조향은 무반응 |

## 5. 우리 연구의 위치 (과장 없이)

| 항목 | 우리 (nav-vla) | 대형 연구 |
|---|---|---|
| 모델 크기 | SmolVLA 약 450M | RT-2 수백억, EMMA 는 Gemini 기반 |
| 언어 조건 | 학습한 정본 문장(2 차선 × 3 속도, 존 목적지, 순항 등). 자유 문장은 파서가 변환 | 자유 문장 직접 |
| 입력 | 카메라 픽셀 + 차량 상태 3 값 (좌표·오도메트리 입력 없음) | 다중 카메라·라이다·지도 등 |
| 환경 | 단일 트랙 시뮬, 실차 이식 준비 중 | 공공도로·대규모 시뮬 |
| 확인한 것 | 문장에 따른 차선·속도 전환(+2.51 m), 데이터로 행동 축 추가, 상황 서술 | – |
| 확인 못 한 것 | 처음 보는 표현(A3 실패), 사전학습 지식으로 대상 지정(미시험) | – |

**강좌에서 쓸 한 문장**: "대형 VLA 에서 보고된 장점 중, 우리 소형 모델로 직접 확인한 것은 '말로 행동 전환'과 '시연으로 행동 추가'이고,
'사전학습 지식으로 처음 보는 대상 다루기'가 어디까지 넘어오는지는 실습에서 함께 시험한다."
