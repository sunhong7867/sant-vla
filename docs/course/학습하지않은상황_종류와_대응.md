# 학습하지 않은 상황 — 종류와 방식별 대응 (2026-10-03 11:51)

단기강좌 실습 정하기([실습 정하기.md](실습%20정하기.md))용. 교수님 요구 "학습하지 않은 것에 대한 동작"을
**어떤 종류의 '학습 안 한 것'인지** 나눠서, 방식별로 어떻게 대응하는지와 우리 트랙에서 무엇을 실습할 수 있는지 정리했다.

---

## 1. 핵심 구분: "무엇을 / 어떻게"

VLA 가 학습 안 한 것을 다루는 통로는 **언어 + 사전학습 지식**이다.

| | 넓어지는가 | 이유 |
|---|---|---|
| **무엇을·어느 것을·어디로** (의미) | 넓어질 수 있음 | 사전학습 VLM 이 단어와 그림의 연결을 이미 가짐. 말로 지정하면 그 지식을 빌림 |
| **어떻게 움직이나** (동작) | 시연 범위 안 | 새 동작은 로봇·차량 시연에서만 배움 (RT-2 논문이 한계로 명시) |

예: RT-2 는 로봇 데이터에 공룡이 없었는데 "멸종된 동물을 집어"에 공룡 장난감을 집었다. "멸종 = 공룡"은 인터넷에서, "집는 법"은 시연에서 왔다.
반대로 시연에 없던 새로운 집기 동작은 못 했다.

**우리 회피 실험이 VLA 다운 실험이 아니었던 이유**: 명령이 늘 "그냥 주행해"로 같아서 언어 통로를 쓰지 않았다.
회피는 순전히 픽셀 → 조향 학습이었고, 이는 일반 E2E 와 같은 실험이며 라이다 규칙으로도 되는 일이다.

---

## 2. 종류 (자율주행)

| 종류 | 무엇이 처음인가 | 실제 도로 예 | 우리 트랙 예 |
|---|---|---|---|
| **A. 환경** | 같은 일, 다른 모습 | 비·눈·안개·야간·역광, 처음 가는 도시, 다른 나라 표지판 | 바닥 무늬·조명 변경, 처음 보는 트랙 |
| **B. 물체** | 데이터에 거의 없는 물체 | 도로 위 동물·낙하물·매트리스, 전복 트럭, 농기계 | 학습 안 한 사람·초록 차 |
| **C. 상황의 의미** | 물체는 알지만 의미가 특이 | 수신호하는 경찰(신호등과 반대 지시), 공사 임시 차선, 구급차 양보, 스쿨버스 정차 | "정지"/"서행" 표지판 보고 행동 바꾸기 |
| **D. 다른 주체의 행동** | 예상 밖 움직임 | 무단횡단, 역주행, 갑자기 끼어드는 차 | (움직이는 장애물 — 현재 시뮬 미지원) |
| **E. 새 조합** | 각각은 봤지만 함께는 처음 | 공사 구간 + 야간 + 보행자 | "빨간 차 앞 정지"와 "콘 왼쪽 통과"를 배우고 "빨간 차 왼쪽 통과" |
| **F. 새 언어 지시** | 처음 받는 말 | "손 흔드는 사람 앞에 세워줘", "파란 트럭 뒤에 주차해" | 학습 안 한 표현, 한국어 명령, 처음 보는 물체를 이름으로 지정 |
| **G. 지름길이 깨지는 상황** | 학습 때 우연히 함께 나온 단서가 사라짐 | 특정 도로에서만 감속을 배움 | 빈 차선에서도 같은 자리에서 꺾기 (우리 r44·sw80) |
| **H. 새 동작** | 시연에 없던 움직임 | – | U턴, 지그재그, 역방향 주행 (우리 실험: 시계방향 시연 0 건 → 좌회전만 하다 이탈) |

## 3. 방식별 대응

| 종류 | 모듈형 (YOLO + 규칙 + 제어) | 일반 E2E (카메라 → 조향) | VLA | 월드 모델 |
|---|---|---|---|---|
| A. 환경 | 검출기 재학습 | 다양한 데이터로 버팀 | 사전학습 시각 인코더로 약간 유리 | 비·야간 장면 생성으로 데이터 보충 |
| B. 물체 — **피하기** | **라이다로 "무언가 있다"만 알면 피함** | 시연 분포 의존 (우리 0/20) | 시연 분포 의존 | 드문 장면 생성 |
| B. 물체 — **무엇인지 알기** | 클래스에 없으면 모름 | 해당 없음 | 사전학습 지식으로 알아볼 여지 | – |
| C. 상황의 의미 | 규칙을 하나씩 추가 | 데이터에 있어야 함 | **강점**: 의미 해석·추론 (DriveVLM, Alpamayo-R1) | 결과 예측으로 계획 보조 |
| D. 다른 주체 행동 | 예측 모듈 규칙 | 데이터에 있어야 함 | 일부 | **강점**: 다음 장면 예측으로 대비 |
| E. 새 조합 | 규칙 충돌 쉬움 | 약함 | 언어 단위 조합에 유리 | 생성으로 보충 |
| F. 새 언어 지시 | 지시마다 파서·코드 | **불가** (입력 없음) | **고유 영역** | – |
| G. 지름길 | 해당 없음 (규칙이라) | 취약 | 취약 (우리 실험) | – |
| H. 새 동작 | 코드로 추가 | 불가 | **불가** | 연구 중 |

**교수님 지적의 정리**: 물체 "피하기"(B)는 라이다만 있어도 된다. VLA 가 필요한 건 **F(언어 지시)와 C(의미)**, 그리고 둘에 걸친
**B 의 "무엇인지 알기"**다. 학생에게 VLA 의 핵심을 보여 주려면 실습이 이 칸에 있어야 한다.

## 4. 로봇 VLA 논문에서 쓰는 일반화 단계 (참고)

| 단계 | 내용 | 운전 버전 | 우리 모델 기대 |
|---|---|---|---|
| 1. 표현 | 같은 일을 다른 말로 | "천천히" → "느긋하게", 한국어 | **낮음** — 정책 자체는 처음 보는 표현 실패 (A3: 학습 표현 +2.51 m, 처음 보는 표현 +0.36 / +0.06 m, 주차 0/8). 지금은 파서가 대신함 |
| 2. 조합 | 아는 것끼리 새 조합 | 물체 × 행동 | 중간 — 실습 설계에 가장 적합 |
| 3. 물체 | 처음 보는 물체를 이름으로 | "사람 앞에서 멈춰" | 중간~낮음 — 시도해 볼 만함 (r38: 서술이 10~14 m 앞 물체 이름 약 45 % 맞힘 → 물체 구분 정보는 모델 안에 일부 있음) |
| 4. 의미·추론 | 성질·관계로 지정 | "하늘색 물체", "두 번째 콘", "탈것 앞" | 낮음 — 대형 모델(RT-2 급) 결과 |

1 단계가 "낮음"인 건 의외일 수 있다. 우리 정책은 정본 문장 몇 개로만 학습해서 표현 다양성이 없었다. 학습 문장에 패러프레이즈를 섞으면
달라질 수 있지만 아직 시험 안 했다.

## 5. 우리 트랙에서 실습 후보

| 후보                   | 종류        | 학습                                      | 평가 (학습 안 한 것)                       | 통과 기준 예                              | 준비                                             |     |
| -------------------- | --------- | --------------------------------------- | ----------------------------------- | ------------------------------------ | ---------------------------------------------- | --- |
| **① 말로 지정한 물체 앞 정지** | F + B + E | 박스·콘·드럼통이 여러 개 놓인 트랙에서 "〈물체〉 앞에서 멈춰" 시연 | "사람 앞에서 멈춰", "초록 차 앞에서 멈춰" (시연 0 건) | 말한 물체 앞에서 서고, 다른 물체는 지나침. 위치는 매번 무작위 | 새 수집·학습 필요. 시뮬 수집기·물체 플릿·무작위 배치는 회피 작업에서 이미 있음 |     |
| ② 물체 × 행동 조합         | E + F     | "빨간 차 앞 정지", "콘 왼쪽 통과"                  | "빨간 차 왼쪽 통과"                        | 지시한 행동을 지시한 물체에서                     | ①이 되면 확장                                       |     |
| ③ 표현 일반화             | F (1 단계)  | 정본 + 패러프레이즈 섞어 학습                       | 처음 보는 표현·한국어                        | 학습 표현 대비 행동 차이 유지                    | 기존 데이터 재라벨로 가능                                 |     |
| ④ 표지판 의미             | C         | "정지" 표지판에서 멈춤 시연                        | 처음 보는 모양의 정지 표지판                    | –                                    | 표지판 모델 필요                                      |     |
| ⑤ 환경 변화              | A         | 기존                                      | 바닥 무늬·조명 변경                         | 차선 유지                                | 쉬움, 다만 VLA 고유성 낮음                              |     |

[실습 정하기.md](실습%20정하기.md) 의 "2. 여러 물체 두고 특정 물체로 이동"이 ①에 해당한다. "1. 학습하지 않은 장애물 회피하기"는
3 절 표대로 라이다 규칙으로도 되는 일이라 VLA 고유성이 낮다.

**①을 추천하는 이유**: 교수님의 두 요구(학습 안 한 물체 + VLA 로만 되는 것)를 동시에 만족하고, 실패해도
"어디까지 사전학습 지식이 넘어오는가"라는 실습 질문 자체가 성립한다.

**정직하게 말할 위험**: SmolVLA(약 450M)는 RT-2 보다 훨씬 작아서 사전학습 지식이 행동까지 넘어올지 모른다.
회피 실험에서도 서술은 물체를 맞혔지만 조향은 반응하지 않았다(말과 행동의 분리). ①을 시작하기 전에 짧은 시뮬 시험으로 확인할 것.

---

## 6. 강좌용 한 문장

"VLA 가 넓히는 것은 '무엇을'이고 '어떻게'는 시연 범위 안에 있습니다. 그래서 VLA 다운 '처음 보는 것' 실험은
처음 보는 물체를 **피하는** 것이 아니라, 처음 보는 물체를 **말로 지정했을 때** 그것을 골라내는지입니다."
