# 차선 밟음 문제 일람과 전 구간 무접촉 작전 (2026-09-14)

오늘 사용자 관찰("곡선/1차선/속도 변경 시 점선 밟음")을 계기로 확정한
문제 목록. 각 항목은 lane_probe(예선 씬, gz 실측 오프셋, 밟음 = 차선
중심에서 0.68 m 초과) 기준.

## 오늘 잡은 것 (수정 완료)

1. **출발 스워브(보통 속도 첫 곡선 밟음)** — 브리지 standstill 카운터의
   학습-서빙 불일치. 학습 에피소드는 전부 still=0에서 시작하는데 서빙은
   스폰 대기 시간을 누적한 채 출발 → still≈cap + 순항 문장 = v9
   GO-prior("관찰 끝, 차선 바꿔 출발") 발동. 수정: 지시 변경 시
   `_still_s` 리셋 + `standstill_cap:=3.5`(학습값) 명시. 콜드 3/3 무접촉.
2. **r16 "inner lane" 표면형 액션 결함** — "Cruise in the inner lane"은
   1차선 위 정상 헤딩 출발에서도 바깥쪽으로 링 이탈 후 오프맵 직진
   (재현). "the left lane"은 정상 추종. GUI `VLA_LANE_WORDS` lane1을
   "the left lane"으로 교체(CCW 전제). A3 계열 표면형 회귀의 액션판.
3. **티어별 곡률 게인 스케줄링** — 브리지가 지시 문장의 티어를 인식해
   `curv_boost_slow/fast:=0.85`(normal 0.95) 적용. 문장 조건화된 티어별
   라인 차이에 대한 서빙단 보정.

## 남은 문제 (본 작전의 대상) — 실측표

| 밟음 비율 | 느림 | 보통 | 빠름 |
|---|---|---|---|
| 2차선(바깥) | 4~18% | **0%** | 9~23% |
| 1차선(안쪽, left 문장) | 24% | 12~17% | 30% |

- 게인 스윕(0.80~1.10)으로 도달한 바닥. 런 간 변동 큼(모델 라인의
  확률적 흔들림).
- 코퍼스 진단: 선생 시연의 중앙값은 티어 무관 0.24~0.28 m로 동급 —
  라이브 티어별 라인 차이는 모델의 문장 조건화가 증폭한 것.
- 결론: **서빙 셰이핑의 한계. 전 구간(차선×티어) 무접촉은 데이터
  정공법** — ① 선생(YOLO 스택)에 속도 스케줄링(전방주시·게인의 속도
  의존) 부여 → ② 티어×차선 균등 재수집 → ③ r17 재학습(r16 레시피에
  신규 코퍼스 합류).

## 작전 순서 (사용자 승인 2026-09-14 "시작!!")

1. 선생 스택 티어×차선 라이브 실측(현재 능력 기준선)
2. 선생 속도 스케줄링 수정 + 동일 실측으로 검증(전 조합 무접촉이 합격)
3. cruise 전용 티어×차선 균등 코퍼스 수집(v10) + 품질 게이트
4. 재라벨(신형 문체·무숫자) → 서버 변환(v9r4c+v10) → r17 학습
   (r16 레시피: v9 액션 제외 유지, v10 액션 포함)
5. lane_probe 매트릭스 + heldout 언어 평가 게이트
