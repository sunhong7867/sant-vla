# v10 액션 진동 — 문제 정리와 해결 계획 (2026-09-15)

## 1. 한 문장 요약

전 조합 무접촉 시연(v10)을 만들어 언어 접지는 역대 최고로 끌어올렸지만,
같은 데이터를 **액션 손실에 넣는 순간** 정책이 곡선에서 ~1.3 m 진동하며
차선을 밟는다 — 데이터는 모든 검사를 통과하는데 학습 결과만 나쁜,
원인 미상의 열린 문제.

## 2. 배경: 왜 v10을 만들었나

목표 "모든 차선·모든 속도에서 차선 안 밟기". r16+서빙 튜닝의 한계
(2차선 보통만 0%, 1차선 12~17%, 느림/빠름 9~23%)의 뿌리가 시연 품질이라
판단, 티어별 라인이 전부 깨끗한 새 선생으로 재시연하기로 함.

- **선생 선정**: YOLO 스택은 1차선 110/150에서 9~20% 밟음(7단 양자화
  조향의 고속 위빙 — 코너 감속·전방주시·EMA 평활 전부 무효).
  **route_oracle + lookahead_gain 0.6**이 전 매트릭스 무접촉(최대
  0.63 m) 실측 통과 → v10 선생으로 채택.
- **v10 수집 결과**: cruise 243ep, 차선×티어 균등(각 33~44), 정상상태
  접촉 **0.0000**(전 조합), 차선 횡단 시연 143개, heldout 7.
  (수집 폭주 사고 1건: 그룹 수 누수로 1000그룹 계획 — 상한 가드 추가,
  덕분에 데이터는 오히려 4배 확보.)

## 3. 증상

v10을 액션 손실에 포함한 모든 런에서 동일:

| 런 | 액션 구성 | 2차선 normal/fast 밟음 |
|---|---|---|
| r16 (기준) | v3y만 (v9 제외) | 4.9% / — → 게인 튜닝 후 **0%** |
| r17 | + v10 전량 | 44% / 59% |
| r18 | + v3y 순항 ×0.2 | 49% / 66% |
| r19 | **v10 단독** (진단) | 49% / 63% |
| r20 | v10 횡단 프레임 절단 | 47% / 68% |

궤적 형태: 차선 위 주행 ↔ 차선 사이(~1.3 m) 이탈을 15~20 s 주기로 반복.
게인 스윕(0.85~1.1, 중립 포함)으로 못 잡음. **언어는 반대로 대승**:
차선 79%·존 45%(역대 최고), 클리어 오언급 0. (장애물 언급은 희석으로
가시 6/25 — 부스트 상향 여지.)

## 4. 기각된 가설 (각각 단일 변수 실험/검사)

1. **두 선생 스타일 혼합** — r18(v3y 순항 감쇠)로 기각.
2. **횡단-시작 시연이 중간갭을 정상화** — r20(미수렴 3,635프레임 액션
   절단)로 기각.
3. **훈련량 부족**(120k 프레임/25k 스텝=1.7에폭) — r20의 12.5k와 25k
   체크포인트 성능 동일(48%≈47%)로 기각.
4. **리샘플 시간/속도 스케일 이상** — dt 중앙값 0.1000, 위치 유도 속도가
   state·target과 정합. 기각.
5. **오라클 lg0.6의 조향 헌팅 학습** — dyaw 부호교대율 0/s, 진폭 v3y와
   동급. 기각.

r19가 준 확정 정보: 원인은 v10 데이터 내부 또는 v10-학습 상호작용
(다른 코퍼스와의 혼합 탓이 아님).

**뼈아픈 반례**: r6는 오라클 시연(v9, lg 0.9)을 자연 빈도로 섞고도
정상 주행했다. v9와 v10의 남은 차이: lookahead 0.6 vs 0.9, cruise 비중
(v10은 전량 cruise 243ep vs v9 cruise는 부분), 수집 시기 환경.

## 5. 해결 계획 (우선순위순)

### P1. 확실한 이득 먼저 굳히기 — r21 (2.2 h, 성공 확실성 높음)
액션 = r16 구성 그대로(v3y만), **언어에만 v10 포함**(액션 가중 0).
얻는 것: 주행 r16급(보통 0% 튜닝 보유) + 언어 역대 최고 + 신형 문체.
"전 속도 무접촉"은 미달이지만 데모 즉시 개선분을 확정하고, 미스터리를
병행 조사할 기반이 된다.

### P2. 학습 없는 결정적 진단 2종 (각 ~30분)
1. **오프라인 청크 대조**: 같은 곡선 프레임(v10 heldout)을 r16과 r19에
   넣어 예측 궤적을 나란히 그린다 — 진동이 "무엇을 보고" 나오는지
   (프레임 조건부인지, 청크 경계 누적인지) 직접 관찰.
2. **학습 타겟 재구성 검증**: v10r 데이터셋에 저장된 액션 청크를
   적분해 원 궤적과 겹쳐본다 — to_lerobot 산출물이 v10에서만 깨지는지
   최종 배제.

### P3. 반례 정면 검증 — lookahead 0.9 재수집 (수집 40분 + 학습 2.2 h)
r6가 소화했던 바로 그 오라클(lg 0.9)로 v10 일부(12그룹)를 재수집해
r19식 격리 학습 → lg 0.6/0.9만 다른 A/B. 0.9가 깨끗하면 원인은
타이트 추종의 (아직 못 잡은) 흔적이고, v10 전체를 0.9로 재수집하면
된다(0.9도 1차선 fast 5.9%였으므로 0.75쯤 절충 탐색).

### P4. 병행 유지
- 현 데모: r16 + 티어 게인(보통 0% 보장) 유지.
- 장애물 언급 회복: 다음 채택 런에서 obstacle-boost 4→8.

## 6. 논문 관점 메모

이 미스터리 자체가 가치 있는 서사다: "시연 품질 지표(위치·속도·조향
전 검사 통과)가 모방학습 결과를 보증하지 않는다 — 같은 선생 계열도
파라미터 하나(lookahead)로 학습 가능성이 갈릴 수 있다"는, 데이터 중심
로보틱스의 평가 방법론 문제 제기. r1~r20 감사 트레일이 그 증거 사슬.
