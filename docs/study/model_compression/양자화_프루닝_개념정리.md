# 양자화·프루닝 개념 정리

> 작성: 2026-10-07. 모델 경량화 공부용 정리. 실험 계획은 [../plan/smolvla_ptq_실험계획.md](../plan/smolvla_ptq_실험계획.md).

---

## 0. 큰 그림

경량화의 목표는 **학습이 끝난 모델을 정확도는 최대한 지키면서 더 작고 빠르게** 만드는 것이다.
대표 기법은 세 가지다.

| 기법 | 줄이는 것 | 한 줄 요약 |
|---|---|---|
| 양자화 (Quantization) | 숫자 하나의 비트 수 | 32/16비트 실수를 8/4비트 정수로 바꾼다 |
| 프루닝 (Pruning) | 숫자의 개수 | 덜 중요한 가중치나 구조를 지운다 |
| 증류 (Distillation) | 모델 자체의 크기 | 큰 모델의 출력을 작은 모델이 따라 배운다 |

세 가지는 함께 쓸 수 있다. 실무에서는 보통 **양자화를 먼저** 적용한다. 적용이 쉽고 효과가 확실하기 때문이다.

## 1. 양자화

### 1.1 기본 수식

```
양자화:  q = clamp( round(x / s) + z,  q_min, q_max )
복원:    x̂ = s · (q − z)
```

- `x`: 원래 실수값, `q`: 정수값, `x̂`: 복원한 값
- `s` (scale): 정수 한 칸이 실수로 얼마인지
- `z` (zero-point): 실수 0 이 어느 정수에 대응하는지
- 오차 `x − x̂` 는 반올림 오차(최대 s/2)와, 범위를 벗어난 값을 자르는 오차(clamp)로 생긴다.

**예시 (INT8, 대칭):** 가중치 범위가 −1.0 ~ +1.0 이면 `s = 1.0 / 127 ≈ 0.00787`, `z = 0`.
값 0.5 는 `round(0.5 / 0.00787) = 64` 로 저장되고, 복원하면 `64 × 0.00787 = 0.504`.

### 1.2 대칭 vs 비대칭

| | 대칭 (symmetric) | 비대칭 (asymmetric) |
|---|---|---|
| zero-point | 0 으로 고정 | 범위에 맞게 정함 |
| 장점 | 계산이 단순하고 빠르다 | 한쪽으로 치우친 분포(예: ReLU 뒤 활성값)를 덜 낭비한다 |
| 주 사용처 | 가중치 | 활성값 |

### 1.3 비트별 메모리 (SmolVLA 약 450M 파라미터 기준, 가중치만)

| 형식 | 비트 | 메모리 |
|---|---|---|
| FP32 | 32 | 약 1.8 GB |
| BF16 / FP16 | 16 | 약 0.9 GB (우리 체크포인트 `model.safetensors` 907 MB 가 이것) |
| INT8 | 8 | 약 0.45 GB |
| INT4 | 4 | 약 0.23 GB |

실제 GPU 사용량은 여기에 활성값, KV 캐시, CUDA 컨텍스트(수백 MB)가 더해진다.

### 1.4 무엇을 양자화하는가

| 표기 | 의미 | 효과 |
|---|---|---|
| W8A16 | 가중치 INT8, 활성값 16비트 | 메모리 절반. 계산은 16비트로 하므로 속도 이득은 "메모리에서 가중치를 읽는 시간"이 줄어드는 만큼 |
| W4A16 | 가중치 INT4, 활성값 16비트 | 메모리 1/4. LLM 에서 가장 흔한 형태 |
| W8A8 | 가중치·활성값 모두 INT8 | 행렬곱 자체가 정수 연산이 되어 하드웨어가 지원하면 가장 빠르다. 활성값 outlier 때문에 정확도 관리가 어렵다 |

**배치 1, 작은 모델**에서는 계산보다 메모리 읽기가 병목인 경우가 많아 W8A16/W4A16 의 효과가 의외로 크고,
W8A8 은 양자화·역양자화 비용 때문에 오히려 느릴 수도 있다. 반드시 측정해서 확인해야 한다.

### 1.5 언제 양자화하는가: PTQ vs QAT

| | PTQ (Post-Training Quantization) | QAT (Quantization-Aware Training) |
|---|---|---|
| 시점 | 학습이 끝난 뒤 변환 | 학습 중에 양자화 오차를 흉내 내며 학습 |
| 필요한 것 | 보정(calibration) 데이터 수백 개 또는 없음 | 학습 데이터와 학습 시간 |
| 정확도 | 8비트는 대부분 충분, 4비트부터 손실이 보인다 | 가장 좋다 |
| 난이도 | 쉽다 | 학습 파이프라인을 고쳐야 한다 |

- **동적(dynamic) 양자화:** 활성값의 scale 을 추론 때마다 실시간으로 계산한다. 보정 데이터가 필요 없다.
- **정적(static) 양자화:** 보정 데이터로 활성값 범위를 미리 정해 둔다. 더 빠르지만 보정 데이터가 실제 분포를 대표해야 한다.

### 1.6 세밀도 (granularity)

scale 을 몇 개의 값마다 하나씩 둘지 정한다.

| 단위 | 설명 | 특징 |
|---|---|---|
| per-tensor | 텐서 전체에 scale 하나 | 단순하지만 큰 값 하나가 전체 정밀도를 떨어뜨린다 |
| per-channel | 출력 채널마다 하나 | 가중치 INT8 의 표준 |
| per-group | 연속된 값 N 개(예: 128)마다 하나 | INT4 에서 사실상 필수. scale 저장 공간이 조금 늘어난다 |

### 1.7 핵심 어려움: outlier

활성값 중 일부 채널이 다른 채널보다 수십~수백 배 큰 경우가 있다(트랜스포머에서 흔함).
범위를 이 큰 값에 맞추면 나머지 대부분의 값이 몇 칸 안에 뭉개진다.

| 기법 | 아이디어 |
|---|---|
| **SmoothQuant** | 활성값의 큰 채널을 나눠 작게 만들고, 그만큼 가중치 쪽에 곱해 준다. 수학적으로 결과는 같고 활성값 양자화가 쉬워진다 (W8A8 용) |
| **AWQ** | 활성값이 큰 채널에 연결된 가중치가 중요하다고 보고, 그 가중치를 키워서 양자화 오차를 줄인다 (W4A16 용) |
| **GPTQ** | 가중치를 열 단위로 하나씩 양자화하면서, 생긴 오차를 아직 양자화하지 않은 열에서 보정한다 (2차 근사 사용) |
| **bitsandbytes LLM.int8() / NF4** | outlier 채널만 16비트로 따로 계산한다 / 정규분포에 맞춘 4비트 눈금을 쓴다 |

### 1.8 민감한 층

모든 층이 똑같이 양자화에 강하지 않다. 보통 아래는 원래 정밀도로 남긴다(mixed precision).

- 첫 층(입력 임베딩, 패치 임베딩)과 마지막 층(출력 projection)
- LayerNorm·softmax 같은 정규화 연산
- **회귀 출력:** 분류는 1등만 맞으면 되지만, 회귀는 값 자체가 결과다. 조향 같은 연속 행동을 내는 층은 작은 오차도 그대로 행동 오차가 된다.

## 2. 프루닝

### 2.1 기본 아이디어

결과에 거의 영향을 주지 않는 가중치를 지운다(0 으로 만들거나 구조째 제거).
가장 단순한 중요도 기준은 **절댓값이 작은 가중치가 덜 중요하다**(magnitude pruning)이다.
이 밖에 기울기·활성값을 함께 보는 기준(예: |w| × |x|, 테일러 근사)도 있다.

### 2.2 세 가지 갈래

| 갈래 | 지우는 단위 | 실제로 빨라지나 | 정확도 |
|---|---|---|---|
| **비구조적 (unstructured)** | 가중치 하나하나 | **일반 GPU 에서는 거의 안 빨라진다** | 50~90% 를 지워도 유지되는 경우가 많다 |
| **구조적 (structured)** | 채널, attention head, 층 통째로 | 어디서든 빨라진다 (행렬이 실제로 작아짐) | 손실이 커서 재학습이 거의 필수 |
| **반구조적 2:4** | 연속 4개 중 2개 | NVIDIA Ampere 이후 GPU 가 하드웨어로 가속 (약 1.5~2배) | 둘의 중간 |

**비구조적 프루닝이 안 빨라지는 이유:** 행렬 크기는 그대로이고 0 이 흩어져 있을 뿐이다.
GPU 행렬곱은 0 을 건너뛰지 않고 그대로 곱한다. 희소 행렬 형식으로 바꾸면 인덱스를 읽는 비용이 생겨,
희소도가 매우 높지 않으면 오히려 느리다. 저장 크기는 압축으로 줄일 수 있다.

RTX 4060, RTX 3090, 4070 Ti, Jetson Orin/Thor 는 모두 2:4 희소 가속을 지원하는 세대다.

### 2.3 일반적인 절차

```
학습된 모델 → 중요도 평가 → 일부 제거 → 재학습(fine-tuning)으로 회복 → 목표 희소도까지 반복
```

한 번에 많이 지우는 것보다 조금씩 여러 번 지우고 회복시키는 편(iterative pruning)이 정확도가 좋다.

### 2.4 재학습 없이 자르는 방법 (LLM 쪽)

| 기법 | 아이디어 |
|---|---|
| **SparseGPT** | GPTQ 와 비슷하게, 가중치를 지운 오차를 남은 가중치로 보정한다 |
| **Wanda** | 중요도를 \|가중치\| × \|입력 활성값 크기\| 로 본다. 보정 없이 자르기만 해도 꽤 잘 된다 |

## 3. 증류 (짧게)

큰 모델(teacher)의 출력, 또는 중간 표현을 작은 모델(student)이 따라 하도록 학습한다.
정답 라벨만 보는 것보다 teacher 의 "부드러운" 출력 분포가 더 많은 정보를 준다.
프루닝으로 줄인 모델을 회복시킬 때 재학습 목표로 쓰기도 한다.

## 4. 양자화 vs 프루닝 비교

| | 양자화 | 프루닝 |
|---|---|---|
| 줄이는 것 | 비트 수 | 개수 |
| 메모리 절감 | 거의 항상 확실 | 구조적이어야 확실 |
| 속도 향상 | 하드웨어·커널 지원이 있으면 | 구조적 또는 2:4 일 때만 |
| 재학습 | PTQ 는 불필요 | 대부분 필요 |
| 도구 성숙도 | 높다 (torchao, bitsandbytes, TensorRT, ONNX Runtime) | 중간 |
| 실무 순서 | **먼저** | 그다음 |

## 5. SmolVLA 에 대입해 보기

우리 주행 모델(v3y 등)은 SmolVLA 구조다.

```
카메라 이미지 ─▶ 비전 인코더(SigLIP) ─┐
지시 문장 ────▶ 토큰 임베딩 ─────────┼─▶ SmolVLM2 언어모델 16층 ─▶ (KV)
state[v, ω, δ] ─▶ state projection ──┘                              │
                                                                     ▼
노이즈 ─▶ action expert (폭 0.75) × flow-matching 10스텝 ─▶ 행동 청크 30×[dx, dy, dyaw]
```

| 부분 | 계산 특징 | 양자화 관점 |
|---|---|---|
| 비전 인코더 | 이미지 1장(512×512 패딩)을 한 번 처리 | 파라미터가 크다. CNN·ViT 는 INT8 에 비교적 강하다 |
| 언어모델 16층 | 프롬프트(이미지 토큰 + 문장 + state)를 한 번 처리 | 파라미터 대부분이 여기. 가중치 양자화 효과가 가장 크다 |
| action expert | 같은 계산을 **10번 반복** (denoising) | 파라미터는 작지만 반복 때문에 지연시간 비중이 클 수 있다. 출력이 연속값이라 민감하다 |
| 출력 projection | 마지막 행동값을 만든다 | 원래 정밀도로 남기는 것이 안전하다 |

**주의할 점**
- **오차 누적:** flow-matching 은 노이즈에서 시작해 10번 조금씩 고쳐 간다. 매 스텝의 작은 양자화 오차가 쌓일 수 있다.
- **폐루프 증폭:** 주행은 출력이 다음 입력(state, 카메라 위치)을 바꾼다. 한 스텝의 작은 조향 오차는 오프라인 지표로는 무시할 만해도, 몇 초 동안 쌓이면 차선 위치가 달라진다. 그래서 **오프라인 오차만 보고 결론 내리면 안 되고 폐루프 주행으로 확인해야 한다.**
- **언어 조건 보존:** 지시 문장에 따라 행동이 달라지는 정도(예: 속도 지시)는 출력 차이가 작은 신호일 수 있다. 양자화 잡음이 이 신호를 묻을 수 있으니 따로 측정한다.
- **flow-matching 스텝 수**(10 → 5)를 줄이는 것도 지연시간을 줄이는 방법이다. 양자화는 아니지만 효과 크기를 비교할 기준이 된다.

## 6. 용어집

| 용어 | 뜻 |
|---|---|
| scale / zero-point | 실수 ↔ 정수 변환 계수 |
| calibration (보정) | 활성값 범위를 정하려고 대표 데이터를 몇 번 통과시키는 과정 |
| weight-only | 가중치만 정수로 저장하고 계산 직전에 실수로 되돌리는 방식 |
| dynamic quantization | 활성값 scale 을 실행 중에 계산 |
| mixed precision | 층마다 다른 정밀도를 쓰는 것 |
| sparsity (희소도) | 0 인 가중치의 비율 |
| 2:4 sparsity | 연속 4개 중 정확히 2개가 0 인 규칙 |
| fake quantization | QAT 에서 실수로 계산하되 양자화→복원을 거쳐 오차만 흉내 내는 것 |
